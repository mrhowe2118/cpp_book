# 运算符与优先级

同一个表达式，**加一对括号和不加，结果可能差很远**。这一节把运算符和优先级讲清楚。

## 本节学会什么

- 掌握算术、赋值、比较、逻辑四类运算符
- 知道**整数除法会截断小数**，以及怎么避开
- 分清负数取余 `-7 % 3` 和位运算 `x & 1` 的差别
- 分清 `i++` 和 `++i`
- 建立"拿不准就加括号"的习惯

## 为什么需要它

看两行看起来差不多的代码：

```cpp
int a = 7, b = 3;
double x = a / b;             // x = 2.0  ← 不是 2.333
double y = 1.0 * a / b;       // y = 2.333 ✓
```

**第一行错在"整数除法"**：`a / b` 两边都是 `int`，结果被截断成 2，然后才赋给 `x`。

::: exam 运算符的坑有个共同特征
它们**都不报错**，只给你一个"看起来合理"的错误答案。

| 坑 | 症状 |
| --- | --- |
| 整数除法截断 | 平均值算出来总是整数 |
| 优先级搞错 | 结果大或小了一个量级 |
| 负数取余/位运算 | 负数输入时答案错 |
| `i++` 和 `++i` 混用 | 结果差 1 |

**这类错误最值得提前学会——因为你在样例上通常测不出来。**
:::

## 最小可运行示例

<!-- expect

---
2 1
-2 -1
2.33
-->
```cpp
#include <cstdio>

int main() {
    int a = 7, b = 3;

    printf("%d %d\n", a / b, a % b);        // 整除 和 取余
    printf("%d %d\n", -7 / 3, -7 % 3);      // 负数的情况
    printf("%.2f\n", 7.0 / 3);              // 浮点除法

    return 0;
}
```

输出：

```text
2 1
-2 -1
2.33
```

### 关键结论

| 表达式 | 结果 | 说明 |
| --- | --- | --- |
| `7 / 3` | `2` | **整数除法：小数部分直接丢掉**（不是四舍五入） |
| `7 % 3` | `1` | 取余数 |
| `-7 / 3` | `-2` | 向 0 截断（不是向下取整） |
| `-7 % 3` | `-1` | 余数的符号跟着**被除数** |
| `7.0 / 3` | `2.333…` | 只要有一边是浮点，就做浮点除法 |

::: pitfall `-7 / 3` 不是 `-3`
数学上向下取整是 `-3`，但 C++ 是**向 0 截断**，得到 `-2`。

**做"向下取整"的除法时，正数和负数的结果不一样。** 需要向下取整时要显式处理：

```cpp
int floorDiv(int a, int b) {
    int q = a / b;
    if ((a % b != 0) && ((a < 0) != (b < 0))) q--;   // 向 0 截断 → 向下取整
    return q;
}
```

竞赛里除非题目明确要求，一般直接用 `a / b` 就行。**但你要知道自己在做什么。**
:::

## 关键过程与易错点

### 一、四类运算符速查

| 类别 | 运算符 | 说明 |
| --- | --- | --- |
| **算术** | `+` `-` `*` `/` `%` | `%` 只能用于整数 |
| **赋值** | `=` `+=` `-=` `*=` `/=` `%=` | `a += b` 等价于 `a = a + b` |
| **比较** | `==` `!=` `>` `<` `>=` `<=` | 结果是 `true` / `false` |
| **逻辑** | `&&` `\|\|` `!` | 与、或、非 |
| **自增自减** | `++` `--` | 加 1 / 减 1 |
| **位运算** | `&` `\|` `^` `~` `<<` `>>` | 见[位运算](/advanced/bit-operations) |

### 二、优先级：谁先算

从高到低（只列常用的）：

```text
高  ┌─ 括号  ( )
    ├─ 单目  !  ++  --  -（负号）  ~
    ├─ 乘除  *  /  %
    ├─ 加减  +  -
    ├─ 移位  <<  >>
    ├─ 比较  <  <=  >  >=
    ├─ 相等  ==  !=
    ├─ 按位与 &
    ├─ 按位异或 ^
    ├─ 按位或 |
    ├─ 逻辑与 &&
低  └─ 逻辑或 ||
```

<!-- expect

---
14
20
1
-->
```cpp
#include <cstdio>

int main() {
    int a = 2, b = 3, c = 4;

    printf("%d\n", a + b * c);        // 2 + 12 = 14（先乘后加）
    printf("%d\n", (a + b) * c);      // 5 * 4 = 20（括号优先）
    printf("%d\n", a < b == 1);       // (2 < 3) == 1 → true == 1 → 1

    return 0;
}
```

::: pitfall `a < b == 1` 这种写法不要用
它能算出结果，但**没人能一眼看出你在说什么**。

**纪律：优先级拿不准就加括号。** 括号不花钱，看错优先级要花时间。

```cpp
if ((a < b) == 1) { }     // 清楚，但还是很怪
if (a < b) { }            // ✓ 直接写这个
```
:::

::: range 三个特别容易错的优先级
| 写法 | 实际含义 | 你可能的误解 |
| --- | --- | --- |
| `a & 1 == 0` | `a & (1 == 0)` = `a & 0` = 0 | 以为是 `(a & 1) == 0` |
| `!a == b` | `(!a) == b` | 以为是 `!(a == b)` |
| `x << 1 + 2` | `x << 3`（加号优先于移位） | 以为是 `(x << 1) + 2` |

**看出来了吗——加括号就全解决了。**
:::

### 三、`i++` 和 `++i`

| 写法 | 含义 | 表达式的值 |
| --- | --- | --- |
| `i++` | 先用 `i`，再加 1 | **加之前**的值 |
| `++i` | 先加 1，再用 `i` | **加之后**的值 |

<!-- expect

---
a=5 b=7 i=7
-->
```cpp
#include <cstdio>

int main() {
    int i = 5;

    int a = i++;      // 先把 5 给 a，然后 i 变成 6
    int b = ++i;      // i 先变成 7，再把 7 给 b

    printf("a=%d b=%d i=%d\n", a, b, i);
    return 0;
}
```

::: pitfall 把 `++` 写进复杂表达式是自找麻烦
```cpp
int c = i++ + ++i;        // ✗ 不同编译器可能给出不同结果
```

这类写法在 C++17 之前甚至是**未定义行为**。

**纪律**：`++i` 和 `i++` 只**单独出现在一行**。

```cpp
i++;                      // ✓
sum += a[i++];            // ✗ 别这么写
```
:::

### 四、整数除法的三个实用场合

**场合 1：判断整除**

```cpp
if (x % 3 == 0) { }        // x 能被 3 整除
```

**场合 2：取某一位**

```cpp
int digit = x / 100 % 10;   // 取百位（先去掉百位以下，再取个位）
```

**场合 3：想算平均值**

```cpp
double avg = 1.0 * sum / n;    // ✓ 先乘 1.0 变成浮点
double bad = sum / n;          // ✗ 整数除法，小数没了
```

::: pitfall `x % 2` 和 `x & 1` 在负数上不一样
两个都能判断奇偶，但**负数时结果不同**：

<!-- expect

---
-1 1
-->
```cpp
#include <cstdio>

int main() {
    printf("%d %d\n", -3 % 2, -3 & 1);   // -1  和  1
    return 0;
}
```

- `-3 % 2` 得到 **`-1`**（余数符号跟被除数）
- `-3 & 1` 得到 **`1`**（取二进制最低位）

所以：

- 判断奇偶建议写 `if (x % 2 != 0)` 或 `if (abs(x) % 2 == 1)`
- 用 `x & 1` 时要知道，**它判断的是"最低位是 1"**，对负数结果是 `1`

**数据保证非负时，两种都行；可能有负数时，务必想清楚。**
:::

### 五、复合赋值：少打字，也少出错

```cpp
sum += a[i];        // 等价于 sum = sum + a[i]
cnt -= 1;
ans *= 2;
x %= MOD;
```

**好处**：左边只写一次，不会出现 `sum = summ + a[i]` 这种手误。

### 六、`%` 和取模

题目要求"答案对 10⁹+7 取模"时：

```cpp
const int MOD = 1000000007;
ans = (ans + x) % MOD;              // 每一步都取模
ans = (a - b + MOD) % MOD;          // ✓ 减法要加 MOD，否则可能出负数
```

**减法取模要 `+ MOD`**，这是个高频细节。

## 动手检查

1. 把示例里的 `7.0 / 3` 改成 `7 / 3`，看输出变成什么。理解"整数除法在执行除法时就截断了"。
2. 写 `printf("%d\n", 7 / 3 * 3);` 和 `printf("%d\n", 3 * 7 / 3);`，结果一样吗？为什么？
3. 把 `a & 1 == 0` 写出来编译运行，输入几个数，看它的实际行为，再加括号对比。
4. 验证 `-7 / 3` 和 `-7 % 3`，然后在纸上用"向 0 截断"的规则复算一遍，确认你理解了这个规则。
