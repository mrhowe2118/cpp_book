# 字符与字符串

题目里的输入不一定是数字。这一节先解决一个基础问题：**字符到底是什么？**

答案可能出乎意料：**字符就是一个整数。**

## 本节学会什么

- 理解 `char` 存的是**编码**（ASCII），本质是个小整数
- 记住几个关键编码，会做"字符 ↔ 数值"的转换
- 会判断字符类型、转换大小写
- 认识转义字符，尤其是 `'\n'` 和 `'\0'`
- 知道读入单个字符时"空格去哪了"

## 为什么需要它

看这段**看起来正确**的代码：

```cpp
char c = '5';
int x = c;              // 你以为 x 是 5
printf("%d\n", x);      // 实际输出 53
```

**`x` 是 53，不是 5。** 因为 `char` 里存的不是"数字 5"，而是**字符 `'5'` 的编码**。

::: exam 记住这一句话就够
**`char` 是一个 1 字节的整数**，只是我们约定：这个整数代表哪个字符，看 ASCII 表。

```text
'0' → 48      'A' → 65      'a' → 97
```

所以你写 `'5'` 的时候，它在内存里就是数字 `53`。

**"字符"和"数字"之间的距离，就是它们编码的差。**
:::

## 最小可运行示例

<!-- expect

---
48 65 97
7
G
-->
```cpp
#include <cstdio>

int main() {
    // ① 三个最关键的编码
    printf("%d %d %d\n", '0', 'A', 'a');

    // ② 字符 → 数值
    char digit = '7';
    printf("%d\n", digit - '0');        // 55 - 48 = 7

    // ③ 小写 → 大写
    char lower = 'g';
    printf("%c\n", lower - 'a' + 'A');  // 'g' - 'a' = 6，6 + 'A' = 'G'

    return 0;
}
```

输出：

```text
48 65 97
7
G
```

三个转换公式，**理解了就再也不用背**：

| 想做什么 | 公式 | 原理 |
| --- | --- | --- |
| 字符 → 数值 | `c - '0'` | 数字字符是**连续排列**的，减去 `'0'` 就是它的值 |
| 数值 → 字符 | `x + '0'` | 反过来加回去 |
| 小写 → 大写 | `c - 'a' + 'A'` | 先求出"是第几个小写字母"，再加到大写区 |
| 大写 → 小写 | `c - 'A' + 'a'` | 同理 |

::: range 关键 ASCII 值（记住这几个就够）
| 字符 | 编码 | 备注 |
| --- | --- | --- |
| `'0'` ~ `'9'` | **48 ~ 57** | 数字字符连续 |
| `'A'` ~ `'Z'` | **65 ~ 90** | 大写字母连续 |
| `'a'` ~ `'z'` | **97 ~ 122** | 小写字母连续 |
| 空格 | 32 | |
| `'\n'` 换行 | 10 | |
| `'\0'` 结束符 | **0** | 下一节的关键 |

**注意**：`'A'`（65）和 `'a'`（97）差了 **32**，不是 26。
所以大小写转换不能简单地加减 26。
:::

## 关键过程与易错点

### 一、判断字符类型：用现成的函数

自己写判断当然可以，但标准库有现成的（需要 `#include <cctype>`）：

| 函数 | 判断 |
| --- | --- |
| `isdigit(c)` | 是不是数字字符 `'0'`~`'9'` |
| `isalpha(c)` | 是不是字母 |
| `isupper(c)` / `islower(c)` | 大写 / 小写 |
| `isalnum(c)` | 字母或数字 |
| `isspace(c)` | 空白（空格、`\t`、`\n`） |
| `toupper(c)` / `tolower(c)` | 转大写 / 转小写 |

<!-- expect
Abc123XY
---
3 3 2
-->
```cpp
#include <cstdio>
#include <cctype>

int main() {
    int digits = 0, upper = 0, lower = 0;

    int c;
    while ((c = getchar()) != '\n' && c != EOF) {
        if (isdigit(c)) digits++;
        else if (isupper(c)) upper++;
        else if (islower(c)) lower++;
    }

    printf("%d %d %d\n", digits, upper, lower);
    return 0;
}
```

输入 `Abc123XY`，输出 `3 3 2`（3 个数字、3 个大写、2 个小写）。

::: pitfall 这些函数返回的不是 `true` / `false`
`isdigit(c)` 返回的是**非零值**（不一定是 1）表示"是"。

所以**不要写** `if (isdigit(c) == 1)`——它可能返回 8 或别的非零值。

```cpp
if (isdigit(c)) { }              // ✓ 直接当条件用
if (isdigit(c) == 1) { }         // ✗ 可能不成立
```
:::

### 二、转义字符：看不见的字符怎么写

有些字符没法直接打出来，要用 `\` 开头的**转义序列**：

| 写法 | 含义 | 注意 |
| --- | --- | --- |
| `'\n'` | 换行 | 最常用 |
| `'\t'` | 制表符（Tab） | |
| `'\\'` | 反斜杠本身 | 路径里要用 |
| `'\''` | 单引号本身 | |
| `'\"'` | 双引号本身 | |
| `'\0'` | **空字符**（编码 0） | 下一节的主角 |
| `'\r'` | 回车 | Windows 换行是 `\r\n` |

::: pitfall `'\0'` 和 `'0'` 完全不同
```cpp
char a = '\0';      // 编码 0，字符串的结束标志
char b = '0';       // 编码 48，字符"零"
```

**一个是"什么都没有"，一个是"数字 0"。** 下一节判断字符串长度时全靠 `'\0'`。
:::

### 三、读入单个字符：空格去哪了？

这是最容易困惑的一点：

```cpp
char c;
cin >> c;              // 输入 "  a"，c 得到 'a'——前面的空格被跳过了
```

`cin >>` 会**跳过所有空白**再读。所以：

| 想读什么 | 正确写法 |
| --- | --- |
| 读一个"可见字符"（跳过空格） | `cin >> c;` 或 `scanf("%c", &c)` 前加空格 |
| **连空格一起读** | `cin.get(c);` 或 `scanf("%c", &c)` |

::: pitfall `scanf("%c")` 会读到上一行的换行符
```cpp
int n;
scanf("%d", &n);
char c;
scanf("%c", &c);       // ✗ 读到的是数字后面的换行符！
```

因为 `%d` 读完数字后，**换行符还留在输入缓冲区里**，`%c` 立刻把它读走了。

**两种修法**：

```cpp
scanf("%d", &n);
scanf(" %c", &c);      // ✓ %c 前面加一个空格：跳过所有空白再读
```

或者用 `cin`（它会自动跳过）：

```cpp
cin >> n;
cin >> c;              // ✓ 跳过换行，读到真正的字符
```

**这和[输入输出](/guide/input-output)里讲的"`cin >> n` 之后 `getline` 读到空行"是同一类问题。**
:::

### 四、字符可以直接比较

因为 `char` 本质是整数，所以能直接比大小：

```cpp
if (c >= 'a' && c <= 'z') { }      // 判断是不是小写字母
if (c >= '0' && c <= '9') { }      // 判断是不是数字字符
if (c < 'A') { }                   // 比 'A' 还小（控制字符等）
```

**这是"连续排列"这个性质的直接应用**——因为 `'a'` 到 `'z'` 是连续的，
所以"在某个范围内"可以用两次比较表示。

::: exam 一个常用技巧：把字符映射成下标
题目给你一串小写字母，要统计每个字母出现几次：

```cpp
int cnt[26] = {0};
cnt[c - 'a']++;        // 'a' → 0，'b' → 1，……，'z' → 25
```

**`c - 'a'` 把字符变成了 0～25 的下标。** 这个技巧在字符串题里到处都是。
:::

### 五、预告：单个字符不够用

`char` 只能存**一个**字符。要存一串（比如一个单词、一整行），需要用：

| 方式 | 说明 | 在哪一节 |
| --- | --- | --- |
| `char s[1005]` | **C 风格字符串**（字符数组 + `'\0'`） | [下一节](/guide/c-strings) |
| `string s` | C++ 的字符串类，更好用 | [再下一节](/guide/cpp-string) |

**两者都能存一串字符，但用法差别很大。** 下一节先讲 C 风格的，因为它是底层机制。

## 动手检查

1. 输出 `'0'`、`'9'`、`'A'`、`'Z'`、`'a'`、`'z'`、`' '`、`'\n'` 的编码值，和上面的表对照。
2. 写一个程序：读入一个小写字母，输出它的大写形式。分别用 `c - 'a' + 'A'` 和 `toupper(c)` 实现。
3. 写一个程序：读入一个数字字符（如 `'7'`），输出它对应的整数。
4. 复现"`scanf("%d")` 后 `scanf("%c")` 读到换行"的问题，然后用 `scanf(" %c")` 修好。
5. 读入一个字符，判断它是数字、大写字母、小写字母还是其他，输出对应的类别。

::: pitfall P1055 是"字符与数值"的分水岭
它要求把 ISBN 字符串里的数字取出来做加权和，最后和校验位比较。

**你需要反复做一件事：把字符 `'7'` 变成数字 `7`。**

```cpp
int d = s[i] - '0';        // 这一步做错了，整题全错
```

做完这道题，"字符和数字不是一回事"就变成你的直觉了。
:::
