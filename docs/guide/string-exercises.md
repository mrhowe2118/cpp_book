# 字符串练习

字符串题的特点是：**思路不难，但细节特别多**——大小写、空格、换行、边界、输出格式。

这一节专门练这些细节。

## 本节学会什么

- 用自测清单确认字符串三节真的学会了
- 掌握字符串题的**通用套路**（不像算法题那样有固定公式）
- 通过一组分层练习，把字符串处理练成手感

## 为什么需要它

字符串题的失分，**绝大多数不是"不会"，而是"漏了"**：

| 漏了什么 | 后果 |
| --- | --- |
| 大小写没统一 | 匹配不上 |
| 末尾多一个空格 | 判 WA |
| `getline` 前没用 `ignore()` | 读到空串 |
| 找不到时没输出 `-1` | 少了特殊情况的分 |
| 单词边界没处理 | 统计结果差 1 |

::: exam 字符串题的检查清单
写完一道字符串题，**逐条过**：

1. **输入方式对不对？**（读单词 `cin >> s`，还是读整行 `getline`）
2. **一行里有没有前导/末尾空格？**（通常是题目故意留的坑）
3. **大小写敏感吗？**
4. **找不到 / 空串怎么办？**（题目说了输出什么吗）
5. **输出的空格和换行**和题目要求一致吗？

**这五条比算法本身更容易丢分。**
:::

## 关键过程与易错点

### 一、字符串题的四个通用套路

| 套路 | 做法 | 典型题 |
| --- | --- | --- |
| **遍历 + 统计** | 一个个字符看，分类计数 | 统计字母/数字/元音 |
| **双指针** | 一头一尾往中间走 | 回文判断、反转 |
| **查找 + 替换** | `find` 定位，`substr` + `erase` + `insert` 改 | 字符串替换 |
| **比较 / 排序** | 直接 `==` `<`，或 `sort` | 字典序、拼数最大 |

### 二、三个必须掌握的小工具

**① 大小写统一**（最常用）

<!-- expect
Hello World
---
hello world
-->
```cpp
#include <iostream>
#include <string>
#include <cctype>
using namespace std;

int main() {
    string s;
    getline(cin, s);

    for (char &c : s) c = tolower(c);      // 注意 &，否则改不到原串

    cout << s << '\n';
    return 0;
}
```

**② 去掉末尾空格 / 换行**

```cpp
while (!s.empty() && (s.back() == ' ' || s.back() == '\r' || s.back() == '\n')) {
    s.pop_back();
}
```

**③ 判断回文**

<!-- expect
level
---
YES
-->
```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string s;
    cin >> s;

    int i = 0, j = (int)s.size() - 1;
    bool ok = true;
    while (i < j) {
        if (s[i] != s[j]) { ok = false; break; }
        i++; j--;
    }
    cout << (ok ? "YES" : "NO") << '\n';
    return 0;
}
```

::: pitfall 范围 `for` 忘了 `&`，改了也不生效
```cpp
for (char c : s) c = tolower(c);        // ✗ c 是副本，s 没变
for (char &c : s) c = tolower(c);       // ✓
```

**这是"我明明转了小写，结果没变"的头号原因。** 见[函数参数与引用](/guide/function-parameters)。
:::

### 三、P1308 的完整解法思路

[洛谷 P1308 统计单词数](https://www.luogu.com.cn/problem/P1308) 是字符串题的典型代表，
值得单独拆一遍。它的要求：

```text
输入：一个单词 word，一整行句子 sentence
输出：word 在句子中出现的次数 和 第一次出现的位置（都是"单词"级别，不是子串）
      找不到则输出 -1
```

**四个必须处理的点**：

| 要点 | 怎么做 |
| --- | --- |
| 单词要整词匹配 | 在词前后**补空格**，然后 `find` 带空格的模式 |
| 大小写不敏感 | 两边都转小写 |
| 统计所有出现位置 | 循环 `find`，每次从上次位置往后找 |
| 找不到 | 输出 `-1` |

::: range 一个很实用的技巧：给两边加空格
```cpp
word = " " + word + " ";
sentence = " " + sentence + " ";
```

这样 `word` 就变成了 `" to "`，用 `find` 找它时**自然就是整词匹配**——
不会把 `today` 里的 `to` 也算上。

**这个技巧能省掉一大段边界判断。**
:::

## 动手检查

1. 用 `getline` 读入一整行，全部转小写后输出。**先故意漏掉 `&`**，看结果有什么不同。
2. 写一个程序判断回文，分别测：`level`、`abba`、`abc`、单个字符、空串。
3. 读入一个句子，把它按**空格**拆开，每个单词一行输出。
4. 复现"`cin >> n` 后 `getline` 读到空串"，然后修好。

## 分层练习

### A 组：基础处理

| 难度 | 题目 | 练什么 |
| --- | --- | --- |
| 基础 | 读入一个单词，倒序输出 | 下标遍历 |
| 基础 | 读入一个单词，判断回文 | 双指针 |
| 基础 | 统计一行里数字、字母、其他字符各多少个 | 遍历 + 分类 |
| 基础 | [洛谷 P5704 字母转换](https://www.luogu.com.cn/problem/P5704) | 大小写 |

### B 组：查找与替换

| 难度 | 题目 | 练什么 |
| --- | --- | --- |
| 巩固 | [洛谷 P1308 统计单词数](https://www.luogu.com.cn/problem/P1308) | **本节的重点题**：整词 + 大小写 + 找不到 |
| 巩固 | [洛谷 P1553 数字反转（升级版）](https://www.luogu.com.cn/problem/P1553) | 小数/分数/百分数的分类处理 |
| 挑战 | [洛谷 P1012 拼数](https://www.luogu.com.cn/problem/P1012) | 自定义比较 + 排序 |

### C 组：综合

| 难度 | 题目 | 练什么 |
| --- | --- | --- |
| 巩固 | [洛谷 P1598 垂直柱状图](https://www.luogu.com.cn/problem/P1598) | 统计 + 格式化输出（**空格很容易错**） |
| 挑战 | [洛谷 P1603 斯诺登的密码](https://www.luogu.com.cn/problem/P1603) | 字符串映射 + 排序 + 前导零 |
| 挑战 | [洛谷 P5587 打字练习](https://www.luogu.com.cn/problem/P5587) | 逐字符比对 + 退格处理 |

::: pitfall P1598 是"格式"的魔鬼题
它要求输出一个**垂直柱状图**，每列要有对齐的空格。

这类题的正确答案**用眼睛是看不出来的**——你必须：

1. 把样例输出复制到文件里
2. 用 `diff` 和你的输出比对（见[评测环境与 Linux 命令](/practice/linux)）

**"看起来一样"和"逐字符一样"是两件事。**
:::

## 立即练习

::: exam 过关门槛
独立完成下面这道题：

> 读入一行文字（可能含空格），要求：
> 1. 统计其中有多少个**单词**（以空格分隔）
> 2. 把每个单词的首字母改成大写后输出
> 3. 输出时单词之间**恰好一个空格**，行末**不要多余空格**

测试三组数据：

- 普通句子
- 有**连续多个空格**的句子
- 只有**一个单词**的句子
