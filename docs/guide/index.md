# 快速入门

这一部分带你从零走到**能独立写出一个完整程序**：环境、语法、数组、字符串、函数、递归。

## 学完你会做到

- 独立完成"读入 → 处理 → 输出"的完整程序
- 看懂编译错误，知道自己错在哪一行、哪一类
- 用数据范围判断该选什么类型、该写多快的算法
- 写出能通过洛谷基础题的代码，并读懂评测结果

## 前置条件

只需要一台能装编译器的电脑。**完全没写过代码也能开始。**

::: pitfall 不要跳过第一节
[开始编程](/guide/getting-started) 看起来最简单，但它是唯一一节"跳过之后会痛苦一整周"的内容。
环境不通，后面每一步你都在怀疑自己。
:::

## 建议节奏

::: range 一周 3～5 节，两个月走完
1. **每节至少写完一道练习。** 只看示例代码不算学会。
2. **不会的题先手算。** 把样例在纸上跑一遍，再回到代码。
3. **卡住超过 40 分钟就看一眼题解思路，然后自己重写。** 硬耗不是坚持，是低效。
4. **做完第 16 节和第 28 节的自测**，判断能不能往下走。
:::
