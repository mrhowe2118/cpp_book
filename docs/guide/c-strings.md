# C 风格字符串

上一节说 `char` 只能存一个字符。要存一串，最早的方案是**字符数组 + 一个结束标志**。

这就是 C 风格字符串。**它有一堆坑，但你必须懂它**——因为这是字符串的底层机制，也是 `string` 的基础。

## 本节学会什么

- 理解 `'\0'` 的作用，以及为什么 `char s[10]` 只能存 9 个字符
- 会读入和输出整串字符（含带空格的一整行）
- 会用 `strlen` / `strcmp` / `strcpy` 这几个常用函数
- **避开最大的坑：不能用 `==` 比较两个字符串**

## 为什么需要它

先回答上一节留的问题：**为什么 `char s[10]` 只能存 9 个字符？**

因为 C 风格字符串需要一个**结束标志** `'\0'`（编码 0）来告诉程序"字符串到这儿就结束了"：

```text
char s[10] = "hello";
内存里实际是：

  s[0]  s[1]  s[2]  s[3]  s[4]  s[5]  s[6] ... s[9]
  'h'   'e'   'l'   'l'   'o'   '\0'   ?       ?
                                ↑
                          结束标志，也占一个位置
```

所以存 5 个字符的 `"hello"`，实际用掉 6 个字节。**必须留 1 个位置给 `'\0'`。**

::: exam 没有 `'\0'` 会怎样
**程序会一直往后读，直到碰巧遇到一个 0。**

结果是：输出后面跟一串乱码，或者数组越界导致 RE。

```cpp
char s[5];
s[0] = 'a'; s[1] = 'b';       // ✗ 忘了写 '\0'
printf("%s\n", s);             // 输出 "ab" 加一串乱码
```

**这是"字符串题莫名输出乱码"的头号原因。**
:::

## 最小可运行示例

<!-- expect
hello
---
长度 = 5
hello
97 98 99 0
-->
```cpp
#include <cstdio>
#include <cstring>

int main() {
    char s[1005];

    // ① 读入一个单词（遇到空白就停）
    scanf("%s", s);

    // ② 求长度
    printf("长度 = %d\n", (int)strlen(s));

    // ③ 遍历：一直走到 '\0'
    for (int i = 0; s[i] != '\0'; i++) {
        printf("%c", s[i]);
    }
    printf("\n");

    // ④ 看看那个结束标志
    char t[10] = "abc";
    printf("%d %d %d %d\n", t[0], t[1], t[2], t[3]);

    return 0;
}
```

输入 `hello`，输出：

```text
长度 = 5
hello
97 98 99 0
```

最后一行 `97 98 99 0` 是 `'a'`、`'b'`、`'c'` 和 **`'\0'`（0）**——
**那个 0 是编译器自动加的。**

## 关键过程与易错点

### 一、四个必须知道的函数（`#include <cstring>`）

| 函数 | 作用 | 注意 |
| --- | --- | --- |
| `strlen(s)` | 求长度（**不含** `'\0'`） | 每次调用都要从头数，循环里别反复调 |
| `strcmp(a, b)` | 比较：相等返回 **0** | 返回负数/正数表示大小关系 |
| `strcpy(dst, src)` | 复制 | `dst` 要够大 |
| `strcat(dst, src)` | 拼接（接到 `dst` 后面） | `dst` 要够大 |

::: pitfall `strcmp` 返回 0 表示"相等"
这和直觉相反——`0` 在 C 里通常表示"假"，但 `strcmp` 用 `0` 表示"相等"。

```cpp
if (strcmp(a, b) == 0) { }      // ✓ 相等
if (strcmp(a, b)) { }           // 不等（非 0 为真）
if (strcmp(a, b) < 0) { }       // a 在 b 前面（字典序）
```

**记法：`strcmp` 返回的是"差"，差为 0 就是相等。**
:::

### 二、最大的坑：不能用 `==` 比较字符串

<!-- expect

---
== 说不相等
strcmp 说相等
-->
```cpp
#include <cstdio>
#include <cstring>

int main() {
    char a[10] = "abc";
    char b[10] = "abc";

    // ✗ 比的是两个数组的"地址"，不是内容
    if (a == b) printf("== 说相等\n");
    else printf("== 说不相等\n");

    // ✓ 比内容要用 strcmp
    if (strcmp(a, b) == 0) printf("strcmp 说相等\n");
    else printf("strcmp 说不相等\n");

    return 0;
}
```

输出：

```text
== 说不相等
strcmp 说相等
```

::: exam 为什么 `==` 不行
数组名在表达式里会"退化"成**首元素的地址**。

所以 `a == b` 比的是"这两个数组是不是同一个位置"——**显然不是**，
哪怕它们的内容一模一样。

**纪律：比较字符串内容，一律用 `strcmp`；`==` 永远得不到你想要的结果。**

（这一点在 [C++ string](/guide/cpp-string) 里不一样——`string` 的 `==` 就是比内容的。
这也是 `string` 更好用的原因之一。）
:::

### 三、读入整行（含空格）

`scanf("%s")` 和 `cin >> s` 都会**遇到空格就停**。要读整行：

| 方式 | 写法 | 说明 |
| --- | --- | --- |
| `fgets` | `fgets(s, sizeof(s), stdin);` | C 风格，会把**换行符也读进来** |
| `cin.getline` | `cin.getline(s, sizeof(s));` | 读到换行，**不保留**换行 |
| `getline` + `string` | `getline(cin, s);` | 需要 `string`（下一节） |

::: pitfall `fgets` 会留下换行符
```cpp
char s[1005];
fgets(s, sizeof(s), stdin);      // 输入 "hello world\n"
                                  // s 里是 "hello world\n" ← 换行也在
```

**要把它去掉**：

```cpp
int len = strlen(s);
if (len > 0 && s[len - 1] == '\n') s[len - 1] = '\0';
```

**不处理的话**，输出会多一个换行，或者比较时永远不相等。
:::

### 四、数组大小必须留够

```cpp
char s[10];
scanf("%s", s);          // 输入 "abcdefghijk"（11 个字符）→ 越界！
```

::: range 字符串题的数组要"多开"
题目说字符串长度不超过 1000，就开：

```cpp
char s[1005];            // ✓ 而不是 char s[1000]
```

**而且 `scanf("%s")` 没有任何长度保护**——输入超了就直接越界写。
在真正的工程里要用 `scanf("%1000s", s)` 限制长度；
竞赛里一般靠"数组开得比题目上限大"来保证安全。

C 风格字符串越界**不一定会立刻崩**——它可能悄悄改掉别的变量，
让你的程序"输出看着差不多但就是不对"。
:::

### 五、什么时候该用 C 风格，什么时候该用 `string`

| | C 风格 `char[]` | `string` |
| --- | --- | --- |
| 定义 | `char s[1005];` | `string s;` |
| 长度限制 | **必须自己预算** | 自动增长 |
| 赋值 / 拼接 | `strcpy` / `strcat` | `=` 和 `+` 直接写 |
| 比较 | `strcmp(a, b) == 0` | `a == b` |
| 越界风险 | **高** | 低 |
| 速度 | 略快 | 略慢（可忽略） |

::: range 本书的建议
**默认用 `string`**（下一节）——代码更短、更安全。

但只要遇到这两种情况，就必须懂 C 风格：

1. **读别人的代码**：老题解、教材里大量使用 `char[]`
2. **需要极致的读入控制**（比如逐字符处理）

**所以这一节不是"过时的知识"，而是"必须认识的底层"。**
:::

## 动手检查

1. 把示例里的 `char t[10] = "abc";` 改成 `char t[3] = "abc";`，编译看看报什么错。
2. 写一个程序：读入两个单词，用 `strcmp` 比较，输出"第一个大 / 相等 / 第二个大"。
3. 故意忘写 `'\0'`：
   ```cpp
   char s[10];
   s[0] = 'a'; s[1] = 'b';
   printf("%s\n", s);
   ```
   看输出是不是乱码。
4. 用 `fgets` 读入一整行（含空格），手动去掉末尾换行符，再输出它的长度。

## 立即练习

| 难度 | 练习 | 练什么 |
| --- | --- | --- |
| 基础 | 读入一个单词，倒序输出 | `strlen` + 下标 |
| 基础 | 读入一个单词，统计每个元音字母出现几次 | 遍历 + 计数 |
| 巩固 | [洛谷 P1308 统计单词数](https://www.luogu.com.cn/problem/P1308) | 读整行 + 大小写 + 统计 |
| 巩固 | 读入两个字符串，输出拼接后的结果（不许用 `string`） | `strcat` + 数组大小 |
| 挑战 | 读入一个句子，把单词顺序倒过来输出 | 分词 + 处理换行 |

::: pitfall 做完这些，你大概会想用 `string`
上面每道题都要**自己算数组够不够大**、**自己记得写 `'\0'`**、**自己记得用 `strcmp`**。

**这正是下一节要解决的问题。**
:::
