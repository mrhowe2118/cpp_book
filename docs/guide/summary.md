## 综合例题：把四层串起来

**题目**：给 n 个学生的姓名和三科成绩，输出总分最高的学生姓名和总分。
如果有多个总分相同，输出**先出现的**那个。

<!-- expect
3
Tom 90 80 70
Jerry 100 100 100
Spike 80 90 95
---
Jerry 300
-->
```cpp
#include <iostream>
#include <string>
using namespace std;

const int MAXN = 1005;

struct Student {
    string name;
    int total;
};

Student st[MAXN];

int main() {
    int n;
    cin >> n;

    int bestIdx = 0;
    for (int i = 0; i < n; i++) {
        int a, b, c;
        cin >> st[i].name >> a >> b >> c;
        st[i].total = a + b + c;

        // 严格大于才更新 → 同分时保留先出现的那个
        if (st[i].total > st[bestIdx].total) bestIdx = i;
    }

    cout << st[bestIdx].name << ' ' << st[bestIdx].total << '\n';
    return 0;
}
```

输入三个学生，输出 `Jerry 300`。

::: range 这道题用到了哪几层
| 代码 | 来自 |
| --- | --- |
| `#include <string>` / `using namespace std;` | 第 2 节 |
| `int a, b, c;` | 第 4 节 |
| `cin >> st[i].name >> a >> b >> c;` | 第 5、19 节 |
| `for (int i = 0; i < n; i++)` | 第 10 节 |
| `struct Student { ... };` | 第 15 节 |
| `st[i].total > st[bestIdx].total` | 第 9 节（严格大于的语义） |
| `cout << st[bestIdx].name << ' ' << ...` | 第 5、19 节 |
| `const int MAXN` + 全局数组 | 第 6、11 节 |

**一道题把四层都用上了。**
:::

::: pitfall 这里有个容易写错的地方
**"同分输出先出现的"** 对应的是 **`>`**（严格大于）。

如果写成 `>=`，那么**同样分数时后面的会覆盖前面的**——输出就变成最后一个同分的人了。

**这类"边界语义"（大于还是大于等于）是排序/打擂台题最常见的丢分点。**
写之前先把中文规则写下来，再翻译成代码。
:::

2. 做一遍综合例题，然后改一个地方：把 `>` 改成 `>=`，

3. 用[控制与数据单元练习](/guide/control-and-data-exercises)和

## 立即练习

::: exam 快速入门的最终验收
不限时间，独立完成下面三件事：

**① 默写能力清单第一、二层涉及的所有代码**
（程序骨架、分支、循环、数组、前缀和、结构体 + `cmp`）

**② 完整做出一道综合题**
要求同时用到：结构体 + 多关键字排序 + 前缀和 + 文件输入输出

**③ 用文件跑通一次完整流程**
建目录 → 写代码 → 造测试数据 → 编译 → 运行 → `diff` 比对

**三件都做到，快速入门就真的学完了。**
:::

## 下一步去哪

### 想继续学工具 → [STL 标准库](/stl/)

`vector`、`sort`、`set`、`map` 能把你的代码缩短一半。
**这是投入产出比最高的一块。**

### 想准备考试 → [考前实战](/practice/)

五道关、数据范围表、骗分、模板——**把已经会的分拿到手**。
离考试还有一两个月的话，建议先读这一部分。

### 想深入语言 → [进阶主题](/advanced/)

类、模板、现代 C++。对复赛得分的直接帮助有限，但对读别人的代码有帮助。

::: range 一个建议的顺序
```text
快速入门 学完
     ↓
① 考前实战（如果考试临近）  ← 优先
② STL（不管考不考试都要学） ← 最实用
③ 进阶主题（有余力再说）
```

**不要跳过 STL。** 它不只是"用现成工具"，它会改变你写代码的方式。
:::
