# 基础语法单元练习

前 7 节是"学"，这一节是"**验收**"。

**不要往下翻，先做完自测。** 通不过就回去补，补完再来。

## 本节学会什么

- 用一份**可验收的自测清单**，确认前 7 节真的学会了
- 通过一组**按知识点分类**的练习，把语法练成手感
- 知道自己现在能不能进入"控制结构"部分

## 为什么需要它

学语法最大的陷阱是**"看懂了"冒充"会写了"**。

> 读代码的时候：嗯，`for` 循环我懂了。
> 写代码的时候：……`for` 的括号里该写什么来着？

::: exam 这一节的用法
1. **先做下面的自测**（合上所有资料，不许翻书）
2. 每一条做不出来 → 记下它属于哪一节 → **回去重读那一节**
3. 全部通过后再做练习
4. 做完练习，你就有资格进入下一部分了

**自测不通过就往下学，是后面所有痛苦的总根源。**
:::

## 关键过程与易错点

### 自测清单：合上资料，逐条动手

::: range 第一组：环境与程序结构（对应第 1～2 节）
- [ ] 能**不看资料**默写出一个完整的 `main` 程序骨架
- [ ] 能说出一条编译命令，并解释 `-std=c++17 -Wall -Wextra` 各是什么
- [ ] 能说出 `#include <iostream>` 为什么必须写
- [ ] 能在终端里编译并运行 `main.cpp`
- [ ] 看到 `expected ';'` 的报错，知道先看**上一行**
:::

::: range 第二组：类型与运算（第 4、7 节）
- [ ] 能说出 `int` 和 `long long` 的范围（大约）
- [ ] 能说出什么情况下必须用 `long long`（提示：乘法、累加）
- [ ] 知道 `7 / 3` 和 `7.0 / 3` 的区别
- [ ] 知道 `-7 % 3` 等于多少，为什么
- [ ] 知道 `i++` 和 `++i` 的区别
- [ ] 能说出至少三个"必须加括号"的场景
:::

::: range 第三组：输入输出（第 5 节）
- [ ] 能写出"读入两个整数、输出它们的和"
- [ ] 知道 `cin >>` 会自动跳过空格和换行
- [ ] 会输出"保留 2 位小数"
- [ ] 会输出"不足两位补 0"（`09:05`）
- [ ] 知道怎么读到文件结束
- [ ] 知道 `cin >> n` 之后用 `getline` 要加什么
:::

::: range 第四组：变量与作用域（第 6 节）
- [ ] 知道全局变量和局部变量在**初值**上的差别
- [ ] 能说出"未初始化变量"会带来什么症状
- [ ] 知道什么是"遮蔽"，能举一个例子
- [ ] 知道循环里声明的 `i` 出了循环还能不能用
- [ ] 知道 `const int MAXN` 为什么是数组尺寸的标准写法
:::

::: exam 判定标准
**任意一组里有两条以上做不到 → 回去重读对应的章节。**

别急着往下走。后面每一个算法都会用到这些基础，
基础不牢的话，你会把"语法不熟"误判成"算法太难"。
:::

### 第二组自测的实际操作：算一算

合上书，在纸上写出下面每个表达式的结果，**再写程序验证**：

| 表达式 | 你的答案 | 实际 |
| --- | --- | --- |
| `7 / 3` | | |
| `7 % 3` | | |
| `-7 / 3` | | |
| `-7 % 3` | | |
| `2 + 3 * 4` | | |
| `(2 + 3) * 4` | | |
| `1.0 * 7 / 3` | | |
| `7 / 3 * 3` | | |

::: pitfall 最后一题很多人会答错
`7 / 3 * 3` 的答案是 **`6`**，不是 7。

因为 `7 / 3` 先算，得 `2`（小数被丢掉），再 `2 * 3 = 6`。

**这题答对了，说明你真的理解了"整数除法在执行时就截断了"。**
:::

::: pitfall 这一阶段"做出来"不是终点
同一道题，请对照这三个标准自评：

| 标准 | 说明 |
| --- | --- |
| ① 能过 | 样例和提交都通过 |
| ② 能说清 | 能给别人讲明白每一行在干什么 |
| ③ 能复现 | 一周后再做一遍，还能独立写出来 |

**只看①的人，会在两章之后发现自己什么都不会。**
:::

## 动手检查

1. 把上面四组自测**全部做一遍**，记录哪几条做不到。
2. 针对做不到的条目，写出对应的章节号，回去重读。
3. 挑 A 组的最后一道题，完整走一遍：读题 → 写代码 → 测样例 → 测边界 → 提交。
4. 把你的编译命令固定下来（`g++ -std=c++17 -Wall -Wextra -Wshadow`），记在纸上。

## 立即练习

这一节本身就是练习。**下面这条是验收线：**

::: exam 进入下一部分的门槛
不翻任何资料，**独立完成**下面这件事，就算过关：

1. 默写出完整的程序骨架（含 `#include`、`main`、`return 0;`）
2. 写一个程序：读入 `n` 和 `n` 个数，输出它们的**和**与**平均值**（平均值保留 2 位小数）
3. 用命令编译并运行它
4. 自己造三组测试数据，其中包含：
   - `n = 1`
   - 数字里包含很大的值（验证不会溢出）
   - 全部相同

**四步都做到，就可以去学[分支结构](/guide/control-flow)了。**
:::

::: range 如果过不了关
不要硬撑。**回到对应章节重读一遍，重做那一节的"动手检查"。**

这本书的每一节都有"动手检查"，就是为了让你在卡住时有一条明确的回路：

```text
做不出来 → 找到对应章节 → 重读 → 重做"动手检查" → 再回来自测
```

**这个回路走得越勤，后面学算法时就越轻松。**
:::
