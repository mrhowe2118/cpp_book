# 指针（选读）

**这一节是选读。** 你不学它也能写竞赛代码——但如果不懂指针，
你会在两个地方一直困惑：**为什么数组传参不复制**、**迭代器到底是什么**。

## 本节学会什么

- 理解"变量在内存里有个地址"这件事
- 会用 `&` 取地址、用 `*` 通过指针读写
- 看懂"数组名就是首元素地址"，以及 `a[i]` 和 `*(a+i)` 的关系
- 知道竞赛里**什么时候真的需要指针**（答案：很少）

## 为什么需要它

先回答一个之前留下的问题。

[函数参数与引用](/guide/function-parameters)里说过：

> 数组作为参数时**不会复制**，函数里改 `a[i]` 会影响到外面。

**为什么数组特殊？** 因为数组传参时传的不是"整个数组"，
而是**第一个元素的地址**。

::: exam 指针就是"地址"
```text
变量 x 放在内存的某个位置，比如地址 0x7ffd1234
  → 指针就是存这个地址的变量

&x   取 x 的地址
*p   取出 p 指向的那个变量的值
```

**理解了这一层，"数组为什么特殊""迭代器为什么能遍历容器"就都有答案了。**
:::

## 最小可运行示例

<!-- expect

---
42
42
100
-->
```cpp
#include <cstdio>

int main() {
    int x = 42;

    int *p = &x;        // p 保存 x 的地址（p 指向 x）

    printf("%d\n", x);   // 直接读 x
    printf("%d\n", *p);  // 通过指针读 x：也是 42

    *p = 100;            // 通过指针改写 x
    printf("%d\n", x);   // x 变成了 100

    return 0;
}
```

输出：

```text
42
42
100
```

::: range 两个符号，成对出现
| 符号 | 名字 | 作用 | 例子 |
| --- | --- | --- | --- |
| `&` | 取地址 | 拿到变量的地址 | `int *p = &x;` |
| `*` | 解引用 | 取出指针指向的值 | `*p = 100;` |

**在声明里，`*` 表示"这是个指针"；在表达式里，`*` 表示"取出它指向的值"。**

```cpp
int *p;      // 声明：p 是一个"指向 int 的指针"
*p = 5;      // 表达式：把 5 写到 p 指向的地方
```

**同一个 `*`，两种含义——和 `&` 的情况一样，看位置。**
:::

## 关键过程与易错点

### 一、指针和数组：它们是一回事

<!-- expect

---
30 30
30 30
-->
```cpp
#include <cstdio>

int main() {
    int a[5] = {10, 20, 30, 40, 50};

    int *p = a;                              // 数组名就是首元素的地址

    printf("%d %d\n", a[2], *(a + 2));       // 两种写法完全等价
    printf("%d %d\n", p[2], *(p + 2));

    return 0;
}
```

输出两行都是 `30 30`。

::: exam 一张表解决所有数组下标的困惑
| 写法 | 等价于 | 含义 |
| --- | --- | --- |
| `a[i]` | `*(a + i)` | 第 i 个元素 |
| `&a[i]` | `a + i` | 第 i 个元素的**地址** |
| `*(a + i)` | `a[i]` | 同上 |

**这解释了三件事**：

1. **数组传参为什么是"传地址"**——因为 `a` 本身就退化成地址
2. **为什么数组传参会丢掉长度**——只传了地址，没传"有多长"
3. **为什么 `sort(a + 1, a + n + 1)` 要这么写**——`a+1` 和 `a+n+1` 是两个地址，表示一个区间
:::

### 二、指针作参数：另一种交换写法

<!-- expect

---
2 1
-->
```cpp
#include <cstdio>

void swapByPtr(int *a, int *b) {
    int t = *a;
    *a = *b;
    *b = t;
}

int main() {
    int x = 1, y = 2;

    swapByPtr(&x, &y);      // 传的是地址

    printf("%d %d\n", x, y);
    return 0;
}
```

输出 `2 1`——交换成功了。

::: range 三种传参方式对比
| 写法 | 调用 | 函数里怎么用 |
| --- | --- | --- |
| 值传递 | `f(x, y)` | 直接改，**改不到外面** |
| **引用** | `f(x, y)` | 直接改，**能改到外面** ✅ |
| 指针 | `f(&x, &y)` | 要写 `*a` 才能改 |

**看出来了：引用更简单。**

引用本质上是"自动解引用的指针"，但用起来不用写 `*` 和 `&`。
**这就是为什么竞赛里推荐用引用。**
:::

### 三、空指针：指向"什么都没有"

```cpp
int *p = nullptr;       // C++11：推荐写法
int *q = NULL;          // 老写法，本质是 0

*p = 5;                 // ✗ 解引用空指针 → 程序崩溃（RE）
```

::: pitfall 空指针解引用 = 段错误
**症状**：运行时直接崩，报"段错误"或 RE。

**什么时候会遇到**：函数要返回一个"没找到"的指针时，返回 `nullptr`，
调用方**必须先判断再解引用**：

```cpp
if (p != nullptr) {
    printf("%d\n", *p);      // ✓
}
```

**注意**：`freopen` 失败时返回的就是 `NULL`——这就是
[文件关](/practice/five-gates/file)里建议检查返回值的原因。
:::

### 四、竞赛里到底什么时候用指针

**说实话：很少。**

| 场景 | 该用什么 |
| --- | --- |
| 想让函数修改参数 | **引用** `int &x`（不是指针） |
| 想避免复制大对象 | **const 引用** `const T &x` |
| 遍历 STL 容器 | **迭代器**（后面学，本质是指针的推广） |
| 动态分配内存 | `vector`（而不是 `new` / `delete`） |
| 链表、树 | 指针（或数组模拟，竞赛更常用数组） |

::: exam 为什么还要学
三个理由：

1. **能读懂别人的代码**——老题解、教材里大量用指针
2. **理解迭代器**——迭代器就是"指针的泛化"，懂了指针就懂了一半
3. **数组与地址的关系**——这解释了前面很多"为什么要这么写"

**但如果你现在时间紧，可以先跳过这一节，后面需要时再回来。**
:::

## 动手检查

1. 输出一个变量的值和它的地址：`printf("%d %p\n", x, &x);`
   （`%p` 是打印地址的格式符）。多运行几次，看地址变不变。
2. 写一个用指针交换两个数的函数，和引用版本对比，数一数多写了几个符号。
3. 验证 `a[2]` 和 `*(a+2)` 完全等价：分别取它们的地址打印，看是不是一样。
4. 把一个空指针解引用（`int *p = nullptr; *p = 1;`），运行看会发生什么。

## 立即练习

| 难度 | 练习 | 练什么 |
| --- | --- | --- |
| 基础 | 用指针遍历数组并输出所有元素 | `*(p+i)` |
| 基础 | 写 `void addOne(int *x)`，通过指针修改 | 指针作参数 |
| 巩固 | 写一个函数返回数组中的最大值和它的地址 | 指针返回位置 |
| 巩固 | 用指针实现字符串复制（不用 `strcpy`） | 指针遍历 |
| 挑战 | 用数组模拟一个栈（用指针指向栈顶） | 指针的实际用途 |

::: pitfall 这一节的目的不是"学会用指针"
而是**"不再怕指针"**。

竞赛的主流写法是：**引用 + STL 容器**，几乎不需要裸指针。

**所以：理解它，但不要刻意去用。** 看到 `*p` 知道在干什么就够了。
:::
