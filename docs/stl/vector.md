# vector 动态数组

普通数组有个硬限制：**大小必须在写代码时就定死**。`vector` 解决这个问题——它能**自动增长**。

## 本节学会什么

- 用 `vector` 定义、添加、访问、删除元素
- 掌握 `push_back` / `size` / `pop_back` / `back` 这几个高频操作
- 知道**什么时候该用 `vector`、什么时候用普通数组**
- 避开两个经典陷阱：下标越界和 `size()` 的无符号性

## 为什么需要它

普通数组的痛点在于**"开多大"这个问题必须提前回答**：

```cpp
const int MAXN = 100005;
int a[MAXN];              // 开小了会越界，开大了浪费内存
```

平时刷题时数据范围是固定的，所以还行。但有两类情况会让普通数组很别扭：

| 情况 | 普通数组的问题 |
| --- | --- |
| **不知道要存几个**（边读边决定） | 只能按上限开，浪费 |
| **需要频繁在末尾追加** | 得自己维护一个"当前长度"变量 |
| **二维但不规则**（每行长度不同） | 只能开 `a[n][m]`，浪费 |
| **函数要返回一个数组** | 数组不能直接返回 |

::: exam vector 的核心优势：长度自己管
```cpp
vector<int> v;

v.push_back(3);      // 追加一个
v.push_back(1);      // 再追加
cout << v.size();    // 2 —— 它会自己记住有几个
```

**不用预设大小，不用维护"当前长度"，不用操心扩容。**
:::

## 最小可运行示例

<!-- expect

---
size = 3
v[1] = 1
1 3 4
after pop: size = 2, back = 3
-->
```cpp
#include <cstdio>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    vector<int> v;

    v.push_back(3);                          // 追加元素
    v.push_back(1);
    v.push_back(4);

    printf("size = %d\n", (int)v.size());
    printf("v[1] = %d\n", v[1]);             // 像数组一样用下标

    sort(v.begin(), v.end());                // 用迭代器表示区间（下一节细讲）
    for (int i = 0; i < (int)v.size(); i++) {
        printf("%d ", v[i]);
    }
    printf("\n");

    v.pop_back();                             // 删掉最后一个
    printf("after pop: size = %d, back = %d\n", (int)v.size(), v.back());

    return 0;
}
```

输出：

```text
size = 3
v[1] = 1
1 3 4
after pop: size = 2, back = 3
```

## 关键过程与易错点

### 一、常用操作一览

| 操作 | 写法 | 说明 |
| --- | --- | --- |
| 定义 | `vector<int> v;` | 空 vector |
| 定长定义 | `vector<int> v(10);` | 10 个元素，初值 0 |
| 追加 | `v.push_back(x);` | 加到末尾 |
| 删除末尾 | `v.pop_back();` | |
| 元素个数 | `v.size()` | **返回无符号数** |
| 是否为空 | `v.empty();` | 比 `size() == 0` 清楚 |
| 访问 | `v[i]` | **不检查越界** |
| 首/尾元素 | `v.front()` / `v.back()` | **容器为空时是未定义行为** |
| 清空 | `v.clear();` | |
| 改大小 | `v.resize(n);` | 变小会删掉多余元素 |
| 预留空间 | `v.reserve(n);` | 提前分配，避免反复扩容 |

### 二、和普通数组的对比

| | 普通数组 | `vector` |
| --- | --- | --- |
| 大小 | 编译期固定 | **运行时可变** |
| 定义 | `int a[100];` | `vector<int> v;` |
| 追加 | 自己维护下标 | `push_back` |
| 长度 | 自己记 | `size()` |
| 越界检查 | 无 | **无**（一样危险） |
| 访问速度 | 最快 | 几乎一样 |
| 内存位置 | 全局数组在静态区 | 在堆上 |
| 能不能返回 | 不能 | **能** |

::: range 竞赛里怎么选
| 场景 | 建议 |
| --- | --- |
| 数据范围固定、就是"开个数组" | **普通数组**（更简单，开全局不占栈） |
| 长度不确定、需要动态追加 | **`vector`** |
| 每行长度不同的二维数据 | **`vector<vector<int>>`** |
| 函数要返回一组数据 | **`vector`** |
| 图论里的邻接表 | **`vector` 数组**（很常用） |

**不用刻意把数组都换成 `vector`。** 数组固定长度时，它就是最合适的选择。
:::

### 三、陷阱一：`vector` 一样会越界

```cpp
vector<int> v;
v.push_back(1);
cout << v[5];        // ✗ 越界！但不会报错
```

::: pitfall `operator[]` 不做任何检查
这一点和普通数组**完全一样**——它只负责算地址，不负责判断合不合法。

想要检查，用 `v.at(5)`（越界会抛异常）。**但竞赛里没人用 `at`**，
因为它慢，而且评测机上异常处理不可控。

**正确做法还是老一套：自己保证下标合法。**

```cpp
if (i < (int)v.size()) cout << v[i];     // ✓ 先判断
```
:::

### 四、陷阱二：`size()` 是无符号数

这个坑在[C++ string](/guide/cpp-string)里出现过，`vector` 完全一样：

```cpp
vector<int> v;           // 空
v.push_back(1);          // 现在 size() == 1

// ✗ 想判断"至少 2 个元素"
if (v.size() - 2 >= 0) { }       // 永远成立！

// ✓ 正确写法
if ((int)v.size() >= 2) { }
```

::: exam 两条等价的安全写法
```cpp
for (int i = 0; i < (int)v.size(); i++)      // ① 强制转换（本书推荐）
for (int i = 0; i < (int)v.size(); i++)      // 都一样
```

或者把长度存下来：

```cpp
int n = (int)v.size();
for (int i = 0; i < n; i++) { }
```

**注意**：如果你在循环里会 `push_back`，`size()` 会变，
所以这时**不能**把长度存到变量里。
:::

### 五、二维 `vector`：处理不规则的表格

```cpp
vector<vector<int>> g(n + 1);      // n+1 个"空行"

g[1].push_back(5);                 // 第 1 行加一个 5
g[1].push_back(7);                 // 第 1 行再加一个 7
g[2].push_back(9);                 // 第 2 行只有一个 9
```

**每一行可以有不同的长度**——这正是普通二维数组做不到的。

**这就是"邻接表"**（图论里存边的标准方式）：

```cpp
vector<int> g[MAXN];               // MAXN 个 vector，每个是一行
g[u].push_back(v);                 // 加一条 u → v 的边
```

::: pitfall `vector<vector<int>>` 的 `>>` 要连着写
```cpp
vector<vector<int> > g;      // C++11 之前必须加空格
vector<vector<int>> g;       // ✓ C++11 起可以连着写
```

**本书用 C++17，所以连着写没问题。** 但看老代码时见到空格别觉得奇怪。
:::

### 六、性能：什么时候需要 `reserve`

`vector` 扩容时会**重新分配一块更大的内存，并把原来的元素搬过去**。
反复扩容有开销。

```cpp
vector<int> v;
v.reserve(100000);            // 提前要够空间
for (int i = 0; i < 100000; i++) v.push_back(i);
```

| 情况 | 要不要 `reserve` |
| --- | --- |
| 已知要存多少个（比如 n 个） | 建议加，一次到位 |
| 不清楚会存多少 | 不加也行，摊还分析下总开销仍是 O(n) |
| 数据量很小（几千） | 无所谓 |

**竞赛里 `reserve` 通常是"可选的优化"**，不加也能过，加上安心。

## 动手检查

1. 把示例里的 `v[1]` 改成 `v[10]`，运行看会发生什么（可能输出垃圾值，也可能不崩）。
2. 写一个程序：不断读入整数到 `vector`，读到 0 停止，然后倒序输出。
3. 用 `v.size() - 2 >= 0` 复现"永远成立"，再用 `(int)` 转换修好。
4. 定义一个 `vector<vector<int>>`，读入 n 行、每行若干个整数（每行个数不同），全部输出。

## 立即练习

| 难度 | 练习 | 练什么 |
| --- | --- | --- |
| 基础 | 读入 n 个数存进 `vector`，倒序输出 | 基本操作 |
| 基础 | 读入 n 个数，用 `push_back` 追加，输出最大值和最小值 | 遍历 |
| 巩固 | 读入一串数（数量未知，读到 0 结束）并排序输出 | `vector` + `sort` |
| 巩固 | 用 `vector<vector<int>>` 存一个 n 行的不规则表格 | 二维 `vector` |
| 挑战 | 用 `vector<int> g[MAXN]` 建一个无向图的邻接表，输出每个点的邻居 | 邻接表 |

::: pitfall 什么时候**不要**用 vector
如果你的数据就是"题目给了 n，最多 10⁵ 个数"，那么：

```cpp
const int MAXN = 100005;
int a[MAXN];                  // ✓ 开全局数组更简单
```

**`vector` 不是"更好的数组"，它是"另一种工具"。**

判断标准：**长度在写代码时能不能确定？**

- 能确定（题目给了上限）→ 普通数组
- 不能确定（边读边决定）→ `vector`
:::
