# bitset 位集

`bitset` 是**定长的二进制位集合**。它最特别的地方是：
**可以像整数一样对整个集合做位运算**，而它的成员函数（数 1 的个数、判空）又比手写更快。

## 本节学会什么

- 定义 `bitset<N>`，会用 `set` / `reset` / `flip` / `count`
- 会用 `to_string()` 输出二进制
- 理解"整个 bitset 一起做位运算"这个能力
- 知道它和 `bool` 数组相比省多少内存
- 知道 `N` 必须是**编译期常量**

## 为什么需要它

先看 `bitset` 和 `bool` 数组的差别：

| | `bool vis[1000005]` | `bitset<1000005> b` |
| --- | --- | --- |
| 内存 | **约 1 MB** | **约 128 KB** |
| 单个置位 | `vis[i] = true` | `b.set(i)` |
| 数有多少个 true | 要写循环 | **`b.count()`（很快）** |
| 整体位运算 | ❌ | **`b1 & b2`** |
| 求反 | 要写循环 | **`~b`** |

::: exam bitset 的两个独门能力
1. **省内存**：`bool` 通常占 1 字节，`bitset` 每一位只占 1 **bit**（省 8 倍）
2. **整体运算**：`&` `|` `^` `~` 直接作用在整个集合上

```cpp
bitset<8> a("10101010");
bitset<8> b("11110000");

cout << (a & b);        // 10100000   ← 一行搞定"求交集"
cout << (a | b);        // 11111010   ← 求并集
cout << (~a);           // 01010101   ← 求补集
```

**"集合运算"用一行代码表达**——这是它最漂亮的地方。
:::

## 最小可运行示例

<!-- expect

---
二进制：00101010
有几个 1：3
第 3 位：1
第 2 位：0
翻转后：00101000
-->
```cpp
#include <cstdio>
#include <bitset>
using namespace std;

int main() {
    bitset<8> b;                 // 8 位，初始全 0

    b.set(1);                    // 把第 1 位置 1
    b.set(3);
    b.set(5);

    printf("二进制：%s\n", b.to_string().c_str());
    printf("有几个 1：%d\n", (int)b.count());
    printf("第 3 位：%d\n", (int)b[3]);
    printf("第 2 位：%d\n", (int)b[2]);

    b.flip(1);                   // 翻转第 1 位
    printf("翻转后：%s\n", b.to_string().c_str());

    return 0;
}
```

输出：

```text
二进制：00101010
有几个 1：3
第 3 位：1
第 2 位：0
翻转后：00101000
```

::: range 位编号的方向：和数组下标一样
```text
bitset<8> b;
b.to_string() 输出 "00101010"

 下标:   7  6  5  4  3  2  1  0
 内容:   0  0  1  0  1  0  1  0
                ↑        ↑  ↑
            set(5)   set(3) set(1)
```

**`set(i)` 里的 `i` 就是下标**——第 `i` 位。
`to_string()` 输出时**最高位在左**，所以看着是"反的"，但下标规则和数组一致。
:::

## 关键过程与易错点

### 一、常用操作

| 操作 | 写法 | 说明 |
| --- | --- | --- |
| 定义 | `bitset<8> b;` | `8` 必须是**编译期常量** |
| 从整数构造 | `bitset<8> b(5);` | 二进制 `00000101` |
| 从字符串构造 | `bitset<8> b("1010");` | 右边对齐 |
| 访问某位 | `b[i]` | 和数组一样 |
| 置 1 / 置 0 | `b.set(i);` / `b.reset(i);` | 不带参数时作用于所有位 |
| 翻转 | `b.flip(i);` | 不带参数时全部翻转 |
| 数 1 的个数 | `b.count();` | |
| 有没有 1 | `b.any();` | |
| 是不是全 0 | `b.none();` | |
| 位数 | `b.size();` | 就是模板参数 `N` |
| 转字符串 | `b.to_string();` | 可以直接 `cout` |
| 转整数 | `b.to_ulong();` / `b.to_ullong();` | 有范围限制 |

::: pitfall `N` 必须是编译期常量
```cpp
int n;
cin >> n;
bitset<n> b;              // ✗ 编译错误！n 不是常量
```

**`bitset` 的大小在编译时就定死了**（这也是它能高效的原因——不需要动态管理）。

**解决**：开一个足够大的固定大小。

```cpp
const int MAXN = 1000005;
bitset<MAXN> b;           // ✓ 用题目给的上限
```

**代价**：声明 100 万个位的 bitset 就固定占约 125 KB，**不管实际用多少**。
（这和"数组按上限开"是一个道理。）
:::

### 二、整体位运算：集合的与或非

<!-- expect

---
a & b = 10100000
a | b = 11111010
a ^ b = 01011010
~a    = 01010101
-->
```cpp
#include <iostream>
#include <bitset>
using namespace std;

int main() {
    bitset<8> a("10101010");
    bitset<8> b("11110000");

    cout << "a & b = " << (a & b) << '\n';     // 交集
    cout << "a | b = " << (a | b) << '\n';     // 并集
    cout << "a ^ b = " << (a ^ b) << '\n';     // 对称差（不同的位）
    cout << "~a    = " << (~a) << '\n';        // 取反

    return 0;
}
```

::: range `&` `|` `^` 和集合的对应关系
| 位运算 | 集合含义 |
| --- | --- |
| `a & b` | **交集**（都在） |
| `a \| b` | **并集**（至少一个在） |
| `a ^ b` | **对称差**（只有一个在） |
| `~a` | **补集**（注意 `bitset` 的位数有限） |

**这就是[位运算](/advanced/bit-operations)里"用整数表示集合"的容器版本**——
区别是 `bitset` 的位数更灵活（可以几百、几万位），而且有现成的成员函数。
:::

### 三、`bitset` 的经典用途

| 用途 | 说明 |
| --- | --- |
| **标记"访问过没有"** | 比 `bool` 数组省内存 |
| **集合交并运算** | 一行 `&` / `\|` |
| **二进制输出** | `b.to_string()` 直接得到字符串 |
| **加速筛法** | 用位运算批量处理（进阶） |
| **状态压缩 DP** | 状态很多时比 `int` 灵活（但通常用 `int` 就够） |

::: pitfall 什么时候**不要**用 bitset
| 场景 | 为什么 | 该用什么 |
| --- | --- | --- |
| 模板参数要运行时决定 | `bitset` 做不到 | `vector<bool>`（也有坑）或手写 |
| 只需要几十位 | `int` / `long long` 更简单 | 用整数做位运算 |
| 需要频繁转成整数 | `to_ulong` 有范围限制 | 直接用整数 |

**判断标准**：需要 **几百位以上**、或者需要**整体位运算**时，`bitset` 才划算。
几十位的话，`int` + 位运算就够了（见[位运算](/advanced/bit-operations)）。
:::

### 四、输出二进制的最简写法

如果你只是想把一个数**输出成二进制**，`bitset` 是最省事的办法：

<!-- expect

---
00000101
00000101
5
-->
```cpp
#include <iostream>
#include <bitset>
using namespace std;

int main() {
    int x = 5;

    cout << bitset<8>(x) << '\n';              // 定长 8 位
    cout << bitset<8>(x).to_string() << '\n';  // 等价写法
    cout << bitset<8>(x).to_ulong() << '\n';   // 转回整数

    return 0;
}
```

输出：

```text
00000101
00000101
5
```

**自己手写"逐位输出"要 5 行，用 `bitset` 一行搞定**——
**补零、定长、方向**这些细节它都处理好了。

::: pitfall `to_ulong()` 溢出会抛异常
```cpp
bitset<64> b;
b.set();                      // 64 位全 1
unsigned long x = b.to_ulong();   // ✗ 在 32 位平台上会抛异常
```

**位数超过平台 `unsigned long` 的宽度时，`to_ulong` 会抛异常。**
64 位时用 `to_ullong()`（`unsigned long long`）。

**输出字符串永远安全**（用 `to_string()`）。
:::

1. 定义一个 `bitset<16>`，用 `set` 把第 0、2、4 位置 1，输出 `to_string()`。
2. 用 `count()` 数 1 的个数，再手写循环数一遍验证。
3. 构造两个 `bitset<8>`，分别输出 `&` `|` `^` `~` 的结果。
4. 用 `bitset<32>(x)` 输出一个整数的二进制，和手写逐位输出的结果对比。
5. 把 `bitset<N>` 的 `N` 换成变量，把编译错误读一遍。

## 立即练习

| 难度 | 练习 | 练什么 |
| --- | --- | --- |
| 基础 | 输出一个整数的二进制表示（定长补零） | `bitset` 构造 + 输出 |
| 基础 | 数一个整数二进制里有多少个 1 | `count()` |
| 基础 | 判断两个集合有没有交集 | `&` + `any()` |
| 巩固 | 用 `bitset` 标记"访问过"，统计有多少个不同的数 | `set` + `count` |
| 巩固 | 输出两个集合的交集、并集、对称差 | 整体位运算 |
| 挑战 | 用 `bitset` 优化埃氏筛（把 `bool` 数组换成 `bitset`） | 内存与速度 |

::: pitfall 位运算的"补集"要注意位数
```cpp
bitset<8> a("10101010");
cout << ~a;                  // 01010101 —— 只在 8 位内取反
```

**`~a` 只在 `bitset` 声明的位数内翻转**，不会像整数那样产生"无限个高位 1"。

**这一点比整数位运算更符合直觉**——但如果你把它转成整数，
高位的行为就要另外考虑了（`to_ulong` 会补 0）。

**记法：`bitset` 的所有操作都"限定在声明的那几位里"。**
:::
