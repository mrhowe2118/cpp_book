# 迭代器与区间

上一节我们写 `sort(v.begin(), v.end())`。**为什么不是 `sort(v, 0, v.size())`？**

这一节解释这个设计，它是所有 STL 操作的通用语言。

## 本节学会什么

- 理解迭代器是"更通用的指针"
- 记住 STL 区间是**左闭右开** `[begin, end)`
- 会用三种方式遍历容器（下标 / 迭代器 / 范围 `for`）
- 看懂为什么普通数组也能直接用 `sort` 这类算法

## 为什么需要它

假设 STL 的排序设计成 `sort(容器, 起点, 终点)`，那会有什么问题？

```cpp
sort(v, 0, v.size());        // 假设的写法
```

| 容器 | 有下标吗 | 能这么写吗 |
| --- | --- | --- |
| `vector` | 有 | 可以 |
| `set` | **没有下标** | ❌ |
| `map` | **没有下标** | ❌ |
| 普通数组 | 有 | 可以 |
| 链表 `list` | **没有** | ❌ |

::: exam 迭代器是为了"统一"
**容器们的内部结构完全不同**（数组、平衡树、链表），
但它们都能提供一种"从头走到尾"的通用方式——**迭代器**。

```text
所有容器都提供：
  begin()  → 指向第一个元素
  end()    → 指向"最后一个元素的下一个位置"

所有算法都只认这两个：
  sort(begin, end)
```

**这就是为什么 STL 的算法能作用在所有容器上。**
:::

## 最小可运行示例

<!-- expect

---
10 20 30
10 20 30
10 20 30
size = 3
-->
```cpp
#include <cstdio>
#include <vector>
using namespace std;

int main() {
    vector<int> v = {10, 20, 30};

    // ① 写全迭代器类型
    for (vector<int>::iterator it = v.begin(); it != v.end(); ++it) {
        printf("%d ", *it);                  // *it 取出当前元素
    }
    printf("\n");

    // ② 用 auto 省事
    for (auto it = v.begin(); it != v.end(); ++it) {
        printf("%d ", *it);
    }
    printf("\n");

    // ③ 范围 for（推荐，最不容易写错）
    for (int x : v) {
        printf("%d ", x);
    }
    printf("\n");

    // end() 指向"最后一个元素的下一个位置"
    printf("size = %d\n", (int)(v.end() - v.begin()));

    return 0;
}
```

三种写法输出完全一样，最后一行验证了 `end()` 的位置。

::: range 为什么 `end()` 不在最后一个元素上
这是**左闭右开**区间 `[begin, end)`：

```text
v = [10, 20, 30]
     ↑           ↑
   begin()     end()
   （10）      （30 的下一个位置，不在容器里）

区间 [begin, end) 表示：从 begin 开始，到 end **之前**结束
  → 正好包含 10、20、30 三个元素
```

**这样做有三个好处**：

1. **空容器也能统一表示**：`begin() == end()`
2. **循环条件好写**：`it != end()` 一直走到"越界前"
3. **长度直接算**：`end() - begin()` 就是元素个数
:::

## 关键过程与易错点

### 一、迭代器和下标的关系

| 想干什么 | 下标写法 | 迭代器写法 |
| --- | --- | --- |
| 第一个元素 | `v[0]` | `v.begin()` → 要 `*v.begin()` 取值 |
| 第 i 个元素 | `v[i]` | `*(v.begin() + i)` |
| 最后一个元素 | `v[v.size() - 1]` | `*(v.end() - 1)` |
| 元素个数 | `v.size()` | `v.end() - v.begin()` |

::: pitfall `v.end()` 不能直接取值
```cpp
cout << *v.end();          // ✗ 未定义行为！end() 不在容器里
cout << *(v.end() - 1);    // ✓ 这才是最后一个元素
```

**`end()` 是"结束标记"，不是"最后一个元素"。**

新手最容易把它当成后者，然后取到一个垃圾值。
:::

### 二、普通数组也是"迭代器"

**指针就是迭代器**。所以普通数组能直接配合 STL 算法：

<!-- expect

---
9 1 5 7 3
1 3 5 7 9
-->
```cpp
#include <cstdio>
#include <algorithm>
using namespace std;

int main() {
    int a[5] = {9, 5, 1, 7, 3};

    // a 是首元素地址（迭代器），a + 4 是最后一个元素，a + 5 才是 end()
    sort(a + 1, a + 4);              // 只排下标 1、2、3

    for (int i = 0; i < 5; i++) printf("%d ", a[i]);
    printf("\n");

    sort(a, a + 5);                  // 整个数组
    for (int i = 0; i < 5; i++) printf("%d ", a[i]);
    printf("\n");

    return 0;
}
```

输出：

```text
9 1 5 7 3
1 3 5 7 9
```

**看懂第一行的输出，就彻底懂了左闭右开**：

```text
原数组：  9  5  1  7  3
下标：    0  1  2  3  4
sort(a+1, a+4) 只动下标 1~3
结果：    9  1  5  7  3
             └─────┘
             这一段被排序了，下标 0 和 4 没被碰
```

**`a + 4` 是下标 4 的地址，但它作为"终点"不参与排序**——
和 `v.end()` 一样，它表示"排到这里为止（不含）"。
:::

### 三、三种遍历方式怎么选

| 写法 | 优点 | 缺点 | 什么时候用 |
| --- | --- | --- | --- |
| `for (int i = 0; i < n; i++)` | 需要下标时方便 | 对没有下标的容器不适用 | 需要下标、需要跳跃访问 |
| `for (auto it = ...)` | 通用 | 写法略长 | 需要删除元素、需要知道位置 |
| `for (int x : v)` | **最简洁** | 拿不到下标 | 单纯遍历（**最常用**） |

::: pitfall 范围 `for` 想改元素要加 `&`
```cpp
for (int x : v) x *= 2;          // ✗ x 是副本，v 没变
for (int &x : v) x *= 2;         // ✓ 该用引用
```

**这是"我明明改了，结果没变"的常见原因**——
和[C++ string](/guide/cpp-string)里 `for (char &c : s)` 是同一个坑。
:::

### 四、区间可以不只是"整个容器"

有了"两个迭代器表示一个区间"，你就能精确指定操作范围：

```cpp
sort(v.begin(), v.end());            // 全部
sort(v.begin(), v.begin() + 3);      // 前 3 个
sort(v.begin() + 1, v.end() - 1);    // 去掉头尾
reverse(v.begin(), v.end());         // 整个翻转
```

**这是"区间"这个设计的价值**：不用为"部分排序"另造一个函数。

### 五、迭代器失效：一个必须知道的危险

**当你增删元素时，之前拿到的迭代器可能失效**：

```cpp
for (auto it = v.begin(); it != v.end(); ++it) {
    if (*it == 3) v.erase(it);       // ✗ erase 后 it 失效，再 ++ 就飞了
}
```

::: pitfall 一边遍历一边删除要特别小心
对 `vector`，正确写法是用 `erase` 的返回值：

```cpp
for (auto it = v.begin(); it != v.end(); ) {
    if (*it == 3) it = v.erase(it);   // ✓ 用返回的新迭代器
    else ++it;                        //     不删才往后走
}
```

对 `set` / `map` 也是同样写法：

```cpp
it = s.erase(it);                     // ✓ 返回下一个位置
```

**简单粗暴的替代方案**：不要边遍历边删。
先标记要删的，遍历完再统一处理。**这往往更不容易出错。**
:::

## 动手检查

1. 输出 `v.begin() == v.end()` 在空 vector 上的结果（应该是 1，即 `true`）。
2. 复现"`*v.end()` 取到垃圾值"，再改成 `*(v.end() - 1)` 看是不是最后一个元素。
3. 用 `sort(a + 2, a + 5)` 只排数组的后三个元素，验证左闭右开。
4. 用三种遍历方式分别把 `vector` 里的元素乘 2（注意引用），确认结果一致。

## 立即练习

| 难度 | 练习 | 练什么 |
| --- | --- | --- |
| 基础 | 用迭代器遍历输出一个 `vector` | `it != v.end()` |
| 基础 | 用 `reverse(v.begin(), v.end())` 翻转数组并输出 | 区间操作 |
| 巩固 | 只排序数组的中间一段 | 左闭右开 |
| 巩固 | 用 `for (auto it = ...)` 找到第一个大于 10 的元素并输出它的下标 | `it - v.begin()` |
| 挑战 | 实现"删除 vector 中所有等于 x 的元素"（不许用 `erase` 逐个删） | 迭代器与区间 |

::: pitfall 第 5 题的提示
不用 `erase` 逐个删，可以用**双指针**：

```cpp
int k = 0;
for (int i = 0; i < (int)v.size(); i++) {
    if (v[i] != x) v[k++] = v[i];        // 把要留的往前搬
}
v.resize(k);                              // 砍掉后面多余的
```

**"先搬再截断"是删除类问题的通用套路**，比逐个 `erase` 快得多（O(n) vs O(n²)）。
:::
