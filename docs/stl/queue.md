# queue 队列

队列是**先进先出**（FIFO）的容器：先放进去的，最先拿出来。

它和栈正好对称——**栈是"后来先走"，队列是"先来先走"**。

## 本节学会什么

- 理解 FIFO（先进先出）
- 掌握 `push` / `pop` / `front` / `back`
- 知道队列和栈在"能访问哪一端"上的区别
- 会用队列做模拟问题
- 知道队列是 **BFS（广度优先搜索）** 的标准工具

## 为什么需要它

想一个真实场景：**排队买票**。

```text
队伍：[小明, 小红, 小刚]

小明先来 → 先买完离开
剩下的：[小红, 小刚]
```

**"先来的先服务"就是 FIFO。** 这就是队列。

::: range 栈和队列的对称关系
| | 栈 `stack` | 队列 `queue` |
| --- | --- | --- |
| 规则 | 后进先出（LIFO） | **先进先出**（FIFO） |
| 从哪进 | 顶部 | **队尾**（`back`） |
| 从哪出 | 顶部（同一个口） | **队头**（`front`） |
| 只能看 | `top()` 栈顶 | `front()` 队头、`back()` 队尾 |
| 典型应用 | 括号匹配、表达式求值 | **BFS、模拟** |
| 生活类比 | 一摞盘子 | 排队买票 |

**栈只有一个口（进和出是同一端）；队列有两个口（一端进，另一端出）。**
:::

## 最小可运行示例

**约瑟夫问题**：n 个人围成一圈报数，报到 3 的出列，求出列顺序。

<!-- expect

---
3 1 5 2 4
-->
```cpp
#include <cstdio>
#include <queue>
using namespace std;

int main() {
    int n = 5;
    queue<int> q;
    for (int i = 1; i <= n; i++) q.push(i);      // 全部入队

    int cnt = 1;
    while (!q.empty()) {
        int x = q.front();                        // 看队头
        q.pop();                                  // 出队

        if (cnt % 3 == 0) {
            printf("%d ", x);                     // 报到 3：出列
        } else {
            q.push(x);                            // 否则回到队尾
        }
        cnt++;
    }
    printf("\n");
    return 0;
}
```

输出 `3 1 5 2 4`。

::: range 这段代码里"队列"的作用
```text
初始：        [1 2 3 4 5]
x=1 出队 → 不是3，回队尾 → [2 3 4 5 1]
x=2 出队 → 不是3，回队尾 → [3 4 5 1 2]
x=3 出队 → 是3，出列！   → [4 5 1 2]
...
```

**"看队头 → 出队 → 处理 → 放回队尾"** ——
这个"转圈"的动作正是队列最典型的用法。

**如果你用数组做，就得手写一个循环下标；用队列则代码自然。**
:::

## 关键过程与易错点

### 一、常用操作

| 操作 | 写法 | 说明 |
| --- | --- | --- |
| 入队 | `q.push(x);` | 放到**队尾** |
| 出队 | `q.pop();` | 拿掉**队头**（**不返回值**） |
| 看队头 | `q.front();` | 最先入队的 |
| 看队尾 | `q.back();` | 最后入队的 |
| 判空 | `q.empty();` | |
| 元素个数 | `q.size();` | |

::: pitfall `pop()` 同样不返回元素，且空队列上操作是未定义行为
```cpp
queue<int> q;
int x = q.front();       // ✗ 空队列，未定义行为
q.pop();                 // ✗ 同样危险
```

**和 `stack` 一样，`queue` 不做任何检查。**

正确写法：

```cpp
if (!q.empty()) {
    int x = q.front();
    q.pop();
}
```

**记法：`stack` 用 `top()`，`queue` 用 `front()`——都只"看"，`pop()` 才真的删。**
:::

### 二、队列也不能遍历

```cpp
for (int x : q) { }      // ✗ 编译错误！queue 没有迭代器
cout << q[0];            // ✗ 也没有下标
```

**理由和 `stack` 一样**：队列的语义是"只能从队头出、队尾进"，
允许随便看中间就破坏了这个抽象。

**需要遍历的话**，用 `deque`（[双端队列](/stl/deque)）或 `vector`。

### 三、用数组模拟队列（循环队列）

竞赛里有时用数组手写队列（更快，或需要访问全部元素）：

```cpp
const int MAXN = 100005;
int q[MAXN];
int head = 0, tail = 0;          // [head, tail) 是队列区间

// 入队
q[tail++] = x;

// 出队
x = q[head++];

// 判空
if (head == tail) { }
```

::: pitfall 手写队列要注意"假的满"
上面的写法里 `tail` 一直往后走，数组很快就"用完了"——
虽然前面已经出队空出位置。

**解决办法**：让下标绕回数组开头（**循环队列**）：

```cpp
tail = (tail + 1) % MAXN;
head = (head + 1) % MAXN;
```

**或者把数组开得足够大**（比如最大入队次数 + 5），就永远用不完。

**竞赛里常用第二种**——简单，只要算准上限。
:::

### 四、队列最重要的用途：BFS

**广度优先搜索**（BFS）就是"一层一层往外扩展"，天生需要队列：

```text
从起点出发：
  ① 起点入队
  ② 取出队头，把它的"没访问过的邻居"全部入队
  ③ 重复 ②，直到队列空
```

::: exam 为什么 BFS 必须用队列
因为 BFS 的规则是"**先发现的先扩展**"——这**就是 FIFO**。

```text
用队列：  先入队的先被处理 → 一层一层整齐地扩展 ✅
用栈：    后入队的先被处理 → 变成"一条路走到黑"（那是 DFS）❌
```

**一句话：BFS 用队列，DFS 用栈（或递归）。**

这是队列最有价值的应用，后面的搜索专题会展开。
:::

### 五、`queue` 和 `deque` 的选择

| | `queue` | `deque` |
| --- | --- | --- |
| 两端操作 | 只能队头出、队尾进 | **两端都能进出** |
| 遍历 | ❌ | ✅ |
| 语义清晰度 | **高**（明确是队列） | 一般 |

**只需要队列语义时用 `queue`**——它用更少的操作表达更明确的意图。

需要两端都能操作时，用 [deque](/stl/deque)。

## 立即练习

| 难度 | 练习 | 练什么 |
| --- | --- | --- |
| 基础 | 把 1～n 依次入队再全部出队输出 | `push` / `front` / `pop` |
| 基础 | [洛谷 P1996 约瑟夫问题](https://www.luogu.com.cn/problem/P1996) | **队列模拟的经典题** |
| 巩固 | [洛谷 P1540 机器翻译](https://www.luogu.com.cn/problem/P1540) | 队列模拟 + 判重 |
| 巩固 | 用队列实现"报数出列"的一般形式（报到 k 出列） | 模拟 |
| 挑战 | 实现 BFS：给一个网格，求从起点到终点的最短步数 | 队列 + BFS |

::: pitfall P1540 是"队列 + 集合"的组合
它的规则是：内存里最多存 m 个单词，查一个新单词时：

- 已经在内存里 → 不管
- 不在内存里 → 把**最早进的**挤出去，装入新词

**"最早进的被挤出去"就是队列**；"在不在内存里"用 `set` 或数组标记。

**这道题把队列和查找结合起来**，是很好的综合练习。
:::
