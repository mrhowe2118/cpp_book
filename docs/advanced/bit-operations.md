# 位运算

位运算直接操作**二进制位**。它不只是"技巧"——**状态压缩**（用整数表示集合）
是很多搜索和动态规划题的基础。

## 本节学会什么

- 掌握六个位运算符：`&` `|` `^` `~` `<<` `>>`
- 记住四个常用操作：判断奇偶、取第 k 位、置位、清零
- 理解**状态压缩**：用一个整数表示一个集合
- 避开三个坑：`&` 和 `&&` 混淆、优先级、`1 << 31` 溢出

## 为什么需要它

先看它能做什么：

| 想做的事 | 普通写法 | 位运算 |
| --- | --- | --- |
| 判断 x 是不是偶数 | `x % 2 == 0` | `(x & 1) == 0` |
| 判断集合里有没有第 i 个元素 | 用 `bool` 数组 | `mask >> i & 1` |
| 枚举所有子集 | 递归 / `n` 层循环 | **`for (mask = 0; mask < (1<<n); mask++)`** |
| 交换两个数 | 用临时变量 | `a ^= b; b ^= a; a ^= b;`（不推荐，只是好玩） |

::: exam 位运算的真正价值在"状态压缩"
**一个整数能表示一个集合。**

```text
n = 3 个元素，用 3 个二进制位表示选没选：
  000  → 一个都没选
  001  → 选了第 0 个
  101  → 选了第 0 个和第 2 个
  111  → 全选了

于是"枚举所有子集"就变成"枚举 0 ~ 2³-1 的所有整数"。
```

**这就是为什么 `n ≤ 20` 的题常常可以用位运算硬搜**
（见[递归与枚举](/guide/recursion-enumeration)里的复杂度上限）。
:::

## 最小可运行示例

<!-- expect

---
1 7 6 -6
10 2
-->
```cpp
#include <cstdio>

int main() {
    int a = 5;      // 二进制 0101
    int b = 3;      // 二进制 0011

    printf("%d %d %d %d\n", a & b, a | b, a ^ b, ~a);
    printf("%d %d\n", a << 1, a >> 1);

    return 0;
}
```

输出：

```text
1 7 6 -6
10 2
```

### 逐位对着看就懂了

```text
      a = 0101  (5)
      b = 0011  (3)
  ───────────────────
    a & b = 0001  (1)   两个都是 1 才是 1
    a | b = 0111  (7)   有一个是 1 就是 1
    a ^ b = 0110  (6)   两个不同才是 1
     ~a   = ...11111010  (-6)   每一位取反

   a << 1 = 1010  (10)      左移一位 = 乘 2
   a >> 1 = 0010  (2)       右移一位 = 除以 2（向下取整）
```

| 运算符 | 名字 | 规则 |
| --- | --- | --- |
| `&` | 按位与 | 都是 1 才得 1 |
| `\|` | 按位或 | 有一个 1 就得 1 |
| `^` | 按位异或 | 不同才得 1 |
| `~` | 按位取反 | 0 变 1，1 变 0 |
| `<<` | 左移 | 乘 2 的幂 |
| `>>` | 右移 | 除以 2 的幂 |

::: pitfall `~a` 得到负数，这不是 bug
`~5` 等于 `-6`，因为整数用**补码**表示：`~x == -x - 1`。

**如果你只想要低几位**，要用掩码：

```cpp
int low3 = x & 7;          // 只保留最低 3 位（7 = 0111）
```
:::

## 关键过程与易错点

### 一、四个必须记住的操作

设 `x` 是整数，`i` 是位编号（**从 0 开始**，最低位是第 0 位）：

| 想做什么 | 写法 | 说明 |
| --- | --- | --- |
| **判断第 i 位是不是 1** | `(x >> i) & 1` | 移到最后一位再看 |
| **把第 i 位置为 1** | `x \|= (1 << i)` | |
| **把第 i 位清为 0** | `x &= ~(1 << i)` | 先取反再与 |
| **把第 i 位翻转** | `x ^= (1 << i)` | |
| **判断奇偶** | `x & 1` | 1 是奇数，0 是偶数 |
| **取最低位的 1**（lowbit） | `x & (-x)` | 树状数组的基础 |

::: range 状态压缩的四个基本操作
用一个整数 `mask` 表示一个集合（第 `i` 位是 1 表示"选了第 i 个元素"）：

| 操作 | 写法 |
| --- | --- |
| 判断 i 在不在集合里 | `if (mask >> i & 1)` |
| 把 i 加入集合 | `mask \|= (1 << i)` |
| 把 i 移出集合 | `mask &= ~(1 << i)` |
| 集合大小（有几个 1） | 用 `__builtin_popcount(mask)` |

```cpp
int mask = 0;
mask |= (1 << 2);              // 加入第 2 个 → mask = 0100 = 4
if (mask >> 2 & 1) { }         // 判断第 2 个在不在 → 在
mask &= ~(1 << 2);             // 移出第 2 个 → mask = 0
```
:::

### 二、用位运算枚举所有子集

<!-- expect

---
{} {1} {2} {12} {3} {13} {23} {123}
-->
```cpp
#include <cstdio>

int main() {
    int n = 3;

    // 用 0 ~ 2^n-1 的每个整数表示一个子集
    for (int mask = 0; mask < (1 << n); mask++) {
        printf("{");
        for (int i = 0; i < n; i++) {
            if (mask & (1 << i)) printf("%d", i + 1);   // 第 i 位是 1 → 选第 i 个
        }
        printf("} ");
    }
    printf("\n");
    return 0;
}
```

输出：

```text
{} {1} {2} {12} {3} {13} {23} {123}
```

**这一段是状态压缩的核心**：外层枚举"哪个子集"，
内层枚举"子集里有哪些元素"。

::: range 和递归枚举的对比
| | 递归枚举子集 | 位运算枚举 |
| --- | --- | --- |
| 代码 | 需要写 `dfs` | **两层循环** |
| 可读性 | 逻辑清楚 | 需要熟悉位运算 |
| 灵活度 | 可以剪枝 | 难以中途剪枝 |
| 适合 | 有复杂约束 | **纯枚举所有子集** |

两者都是 O(2ⁿ)。**约束简单时用位运算，要剪枝时用递归。**
:::

### 三、三个坑

::: pitfall 坑一：`&` 和 `&&` 混淆
```cpp
if (x & 1) { }          // ✓ 判断奇偶
if (x && 1) { }         // ✗ 逻辑与！只要 x 非零就成立
```

**症状**：条件永远成立，或者结果莫名其妙。

**注意**：`x & 1` 的结果是 `0` 或 `1`，可以当条件用
（0 为假，非 0 为真）——所以 `if (x & 1)` 是合法的。
:::

::: pitfall 坑二：优先级
```cpp
if (x & 1 == 0) { }              // ✗ 实际是 x & (1 == 0) = x & 0 = 0
if ((x & 1) == 0) { }            // ✓
```

**规律**：`==` 的优先级**高于** `&` `|` `^`。

**记法：位运算和比较混用时，一律加括号。**
（见[运算符与优先级](/guide/operators)）
:::

::: pitfall 坑三：`1 << 31` 会溢出
```cpp
int x = 1 << 31;                 // ✗ 溢出！int 的范围是 ±2^31-1
long long y = 1LL << 31;         // ✓ 用 long long
```

**规则**：移位时，如果位数可能达到 30 以上，**用 `1LL`**：

```cpp
long long mask = 1LL << i;       // ✓
if (x & (1LL << 40)) { }         // ✓
```

**另一个相关坑**：`1 << n` 当 `n = 31` 时，`int` 装不下 2³¹。
所以 **`n ≤ 20` 的枚举上限（`1 << 20` 约 10⁶）不是随便定的**——
`int` 能安全表示的子集范围大概就到 `n = 30`。
:::

### 四、`__builtin_popcount`：数 1 的个数

GCC 内置函数（**竞赛里可以用**）：

| 函数 | 作用 |
| --- | --- |
| `__builtin_popcount(x)` | `int` 里 1 的个数 |
| `__builtin_popcountll(x)` | `long long` 里 1 的个数 |
| `__builtin_ctz(x)` | 末尾有多少个 0 |
| `__builtin_clz(x)` | 开头有多少个 0 |

```cpp
int mask = 0b1011;                            // 11，有 3 个 1
printf("%d\n", __builtin_popcount(mask));     // 3
```

::: pitfall 这些是 GCC 扩展，不是标准 C++
在 `g++`（NOI Linux 用的就是它）上没问题。

**但在别的编译器上可能不存在。** 如果需要可移植的写法：

```cpp
int popcount(int x) {
    int cnt = 0;
    while (x) { cnt += x & 1; x >>= 1; }
    return cnt;
}
```

**竞赛里直接用 `__builtin_popcount` 就好**（省事又快）。
:::

### 五、什么时候该想到位运算

| 看到这个 | 想什么 |
| --- | --- |
| `n ≤ 20` 且要枚举所有子集 | **状态压缩枚举** |
| 需要表示"某几个元素选没选" | **用一个整数当集合** |
| 判断奇偶、取某一位 | 位运算 |
| 树状数组、状压 DP | 位运算基础 |
| 只想写短一点 | 位运算（但要保证可读） |

::: pitfall 不要为了"炫技"用位运算
```cpp
if (x & 1) { }               // 可以
a ^= b ^= a ^= b;            // ✗ 交换两数，可读性极差，还有未定义行为风险
```

**判断标准：位运算用在这里，是"更清楚"还是"更短"？**

- "更清楚"（判断奇偶、压缩状态）→ 用
- 只是"更短"→ 别用，可读性更重要

**竞赛代码也是要给人看的**（见[注释与代码风格](/guide/comments)）。
:::

## 动手检查

1. 输出 5、3、1 的二进制表示（提示：用 `for` 从高位到低位输出每一位）。
2. 用位运算判断一个数是奇数还是偶数，再取它的第 3 位。
3. 复现"`x & 1 == 0`"和"`(x & 1) == 0`"的差别。
4. 用 `__builtin_popcount` 统计一个整数里有多少个 1，再用循环手写一遍验证。
5. 把子集枚举的输出顺序和[递归枚举子集](/guide/recursion-enumeration)的输出对比。

## 立即练习

| 难度 | 练习 | 练什么 |
| --- | --- | --- |
| 基础 | 输出一个整数的二进制表示 | 逐位取 |
| 基础 | 判断一个数是不是 2 的幂（提示：`x & (x-1)`） | 位运算技巧 |
| 巩固 | 用位运算枚举 `{1..n}` 的所有子集 | 状态压缩 |
| 巩固 | 统计一个整数有多少个二进制 1 | `popcount` |
| 挑战 | 用状态压缩解"n 个数选若干个，使和为 x"（`n ≤ 20`） | 状态压缩的实战 |
| 挑战 | [洛谷 P1044 栈](https://www.luogu.com.cn/problem/P1044) 或任意状态压缩 DP | 位运算的进阶应用 |

::: pitfall "判断 2 的幂"是个漂亮的例子
```cpp
bool isPowerOfTwo(int x) {
    return x > 0 && (x & (x - 1)) == 0;
}
```

**为什么成立？** 2 的幂的二进制是"只有一位是 1"（如 `1000`），
减 1 之后变成"这一位变 0，后面全变 1"（`0111`），两者相与必然是 0。

**这个技巧（`x & (x-1)`）能"消掉最低位的 1"**，
在统计位数的题目里也常用。
:::
