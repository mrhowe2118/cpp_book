# 进阶主题

这一部分不是 CSP-J 的必需内容。**它的作用是：让你在读懂别人的代码时不吃力，在写封装时更顺手。**

## 什么时候看

| 你的情况 | 建议 |
| --- | --- |
| 还在打 CSP-J / S 第一轮 | **先别看**，把 [快速入门](/guide/) 和 [STL](/stl/) 打扎实 |
| 已经能稳定做出 T1、T2 | 值得看：类、重载、模板 |
| 想读懂题解里的高级写法 | 值得看：现代 C++、`lambda`、位运算 |
| 单纯好奇 | 从[类与对象入门](/advanced/classes)开始 |

::: pitfall 不要在考前进阶
进阶内容对**复赛得分的直接帮助很小**，而学习成本很高。
考前两周去学模板元编程，是把时间花在了收益最低的地方。

**先把五道关和 STL 吃透，再回来。**
:::

## 一条提醒

::: range 进阶内容要"用得上"才算学过
这些内容的特点是：**看懂了不等于会用**。

建议每学一个特性，**回到你之前写过的题，用它重写一遍**。
比如学完 `lambda`，把之前 `sort` 里手写的比较函数全部换成 `lambda` 版本——这样才算真的会了。
:::
