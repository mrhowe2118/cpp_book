# 学习建议：怎么刷题

**"刷题"是信奥学习的主体，但"刷了多少道"几乎和进步无关。**

这一节讲怎么让每一道题都产生进步。

## 本节学会什么

- 分清"看懂题解"和"自己做出来"——这是最关键的一条
- 知道该按什么难度比例选题
- 学会"卡住 30 分钟"的原则
- 会用错题本
- 知道哪些做法是"看起来努力，其实无效"

## 为什么需要它

先看一个常见场景：

> 今天刷了 10 道题！
> 其中 8 道看了题解才会，2 道自己做的。
> 一周后——这 10 道题一道也想不起来。

::: exam 刷题的唯一有效标准：**独立完成**
| 做法 | 你练到了什么 |
| --- | --- |
| 看题解 → 看懂 → 抄一遍 | **"看懂代码"的能力**（不是做题能力） |
| 看题解 → 合上 → 自己重写 | **做题能力**（有效） |
| 自己想 → 做出来 | **做题能力**（最有效） |
| 自己想 → 卡住 → 看题解 → 重写 → 隔天再做一遍 | **做题能力**（最有效） |

**判断标准很简单：这道题的代码，你能不能在白纸上从零写出来？**
:::

## 关键过程与易错点

### 一、做题的四个层次

同一道题，四种"会"的程度完全不同：

| 层次 | 表现 | 算不算会 |
| --- | --- | --- |
| ① 看懂 | 读题解能明白每行在干什么 | ❌ 不算 |
| ② 默写 | 合上题解能照抄出来 | ❌ 基本不算 |
| ③ 独立 | 不看任何资料能写出来 | ✅ **算** |
| ④ 讲清 | 能给别人讲明白为什么这么做 | ✅✅ 真的会了 |

::: exam 用"第 ④ 层"检验自己
**最有效的自测方式：把这道题讲给一个同学听。**

- 讲到哪里卡住 → 那就是你真正没懂的地方
- 讲完对方能自己写出来 → 你是真的会了

**没有人可讲时，就写一段"思路总结"**（不用代码，纯文字说清"为什么这么做"）。
:::

### 二、选题的难度比例

这是最容易做错的一件事。

::: range 推荐的难度分布
| 难度 | 占比 | 作用 |
| --- | --- | --- |
| **能独立做出来** | 约 60% | **巩固**（保持手感） |
| **要想一会儿能做出来** | 约 30% | **成长**（主要进步来源） |
| **完全不会，看题解** | 约 10% | **拓展**（学新思路） |

**注意 60% 那一档**：很多人觉得"这题我会了，不用做了"——
**其实巩固是必要的**，它让你在考场上"不用想就能写对"。

**注意 10% 那一档**：全是难题会打击信心，也学不动。
:::

::: pitfall 只做难题和只做简单题都不行
| 做法 | 后果 |
| --- | --- |
| 只做简单题 | 考试遇到难题直接懵，分数上不去 |
| 只做难题 | 基础不牢，简单题也丢分；且容易放弃 |

**正确的节奏是"大部分时间在舒适区边缘"。**
:::

### 三、卡住了怎么办：30 分钟原则

::: exam 一道题卡住超过 30 分钟，就该看题解了
**但看题解的方式很重要。**

```text
① 想 30 分钟（真的想，不查资料）
      ↓ 还不会
② 看题解的"思路"部分（不要看代码！）
      ↓ 还不会
③ 看代码，但只看关键的几行
      ↓
④ 合上一切，自己从零重写一遍
      ↓
⑤ 写完对照，记录自己卡在哪一步
      ↓
⑥ 隔一天，再独立做一遍
```

**关键在④和⑥**：不重写 = 白看题解；不做第二遍 = 下次还是不会。
:::

::: pitfall "再想 5 分钟"是最贵的一句话
它经常会变成"再想 50 分钟"，而且结果还是不会——只是浪费了时间。

**用闹钟**。30 分钟到了就看题解，**这不是放弃，是效率**。
:::

### 四、错题本：最被低估的工具

**记录什么？**

| 记 | 不记 |
| --- | --- |
| **为什么错了**（哪一步想歪了） | 完整的题解代码 |
| **正确思路的关键转折点** | 题面抄写 |
| **下次遇到类似的题该注意什么** | "这题很难"这种描述 |

**格式示例：**

```text
题：P1102 A-B 数对
日期：10-15
我的做法：双重循环枚举 → 超时
错在哪：没想到"排序 + 二分"
关键点：把 A - B = C 变成 A = B + C，然后对每个 B 去查找 B + C
提醒：看到"数对 + 计数"，先想排序能不能降复杂度
重做情况：10-17 独立做出 ✅ / 10-24 又做一遍 ✅
```

::: range 什么时候回头做
| 时间 | 做什么 |
| --- | --- |
| 当天 | 做完立刻记错题本 |
| **第 2～3 天** | 独立重做一遍（**这一步最关键**） |
| 第 1～2 周 | 再重做一遍 |
| 考前 | 只看"提醒"那一列 |

**复习的价值远大于做新题。** 做 10 道新题，不如把 3 道错题真正弄会。
:::

### 五、无效努力清单

::: pitfall 这些做法看起来努力，其实收益很低
| 做法 | 为什么无效 |
| --- | --- |
| 抄题解但不重写 | 练的是"抄写" |
| 只看"困难"标签的题 | 基础不牢，越做越挫败 |
| 做题不做记录 | 同样的错会犯很多次 |
| 每天换不同专题 | 每个都浅尝辄止 |
| 花很多时间整理漂亮的笔记 | 整理 ≠ 理解 |
| "今天做了 10 道题"当作目标 | 目标应该是"独立做出 X 道" |
:::

### 六、不要做的事

| 别做 | 原因 |
| --- | --- |
| **比较进度** | 别人的节奏和你无关；比进度只会焦虑 |
| **不会就搜答案** | 30 分钟原则 |
| **只看不做** | 编程是技能，必须动手 |
| **跳过基础题** | 基础题练的是"不假思索地写对" |
| **用"题数"当唯一目标** | 应该用"独立完成数"和"能讲清数" |

## 动手检查

1. 统计你最近 20 道题：**能独立做出几道？** 如果低于 60%，说明选题太难或基础不牢。
2. 挑一道"看题解做过"的题，**合上所有资料重写一遍**，看你卡在哪。
3. 建立错题本（纸质或电子都行），按上面的格式记 3 道题。
4. 给自己设一个 30 分钟闹钟，做一道目前不会的题，体验一次"到点看题解"。

## 立即练习

::: exam 一周刷题计划（可直接照做）
| 项目 | 量 |
| --- | --- |
| 能独立做出的题（巩固） | 6 道 |
| 要想一会儿的题（成长） | 3 道 |
| 看题解的题（拓展） | 1 道 |
| **错题重做** | **3 道（上周的）** |
| 写思路总结 | 每道新题 3 行 |

**关键不是数量，而是"重做"和"总结"这两栏不能空。**
:::

::: range 怎么判断"这周有进步"
不要用"做了多少道题"，用这三个：

1. **上周看题解才会的题，这周能独立做出了吗？**
2. **有没有一道题，你现在能给别人讲清楚了？**
3. **有没有一个以前常犯的错误，这周没再犯？**

**三题里有一个"是"，就是有效的一周。**
:::
