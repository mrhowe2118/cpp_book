# 考场时间分配与心态

前几节讲的都是"怎么写对"。这一节讲的是**另一件同等重要的事：**在有限的时间里，
把你会的那些分数**按顺序拿到手**。

## 本节学会什么

- 拿到一份可执行的**四阶段时间表**
- 学会"卡住 10 分钟就换题"的判断规则，避免死磕
- 知道慌了、崩了的时候该做什么
- 拿到一份赛后复盘模板，把每场模拟赛变成进步

## 为什么需要它

考场上的失败，很多时候**不是不会做，而是时间用错了地方**：

> 前两个小时死磕 T3，什么也没写出来。
> 剩下两个小时慌了，T1 写错了没检查，T2 没时间写。
> 最后：T1 拿 30 分，其余 0 分。

::: exam 一个反直觉的事实
**同样会做 T1 和 T2 的两个人，成绩可能差 100 分。**

差别不在能力，在于：

- 一个人先花 40 分钟把 T1、T2 稳稳写完、检查完，再去做 T3
- 另一个人先在 T3 上耗了两小时，T1、T2 都在慌乱中赶完

**时间分配是独立于算法能力的一门技能，而且它更容易练。**
:::

## 四阶段时间表

复赛时长通常是 3.5～4 小时（**以你所在省份当年须知为准**）。
下面以 4 小时为例，其他时长按比例调整。

| 阶段 | 时间 | 目标 | 关键动作 |
| --- | --- | --- | --- |
| ① 通读 | 0:00–0:15 | **知道这四题分别是什么** | 四题全读，标数据范围和分档 |
| ② 拿分 | 0:15–1:15 | **四题都有一份能交的代码** | 每题先写暴力，交上去 |
| ③ 主攻 | 1:15–3:20 | **把最容易的那题往上打** | 从性价比最高的题开始优化 |
| ④ 收尾 | 3:20–4:00 | **一分不丢** | 只做检查清单，不改逻辑 |

### ① 通读阶段（前 15 分钟）

**不要一上来就打开 T1 开始写。**

| 要做 | 为什么 |
| --- | --- |
| 四题**全部**读一遍 | 才知道哪题最容易，避免"开局就选错" |
| 每题标出**数据范围** | 直接决定用什么算法（见[数据范围表就是给分表](/practice/data-range)） |
| 标出**分值分布** | 判断哪题值得花时间 |
| 记下**文件名的要求** | 每题的文件名不一样，先记下来 |

::: pitfall 通读时不要动键盘
15 分钟不写代码，很多学生会焦虑。但**这 15 分钟能省下后面 30 分钟**：

- 你避免了"在难题上死磕"
- 你提前看到了最简单的那题
- 你知道了每题的分档，能规划"最低拿多少分"

**在纸上记，不要在脑子里记。** 写到纸上你才能同时比较四道题。
:::

### ② 拿分阶段（第 15～75 分钟）

**目标：让四道题都有一份能在评测机上跑的代码。**

顺序：从**最容易**的那题开始，不是从 T1 开始。

对每一题：

```text
1. 写暴力（或者你会的最简单的做法）
2. 用样例测一遍
3. 检查 freopen 文件名
4. 交上去  ← 锁定这部分分
5. 记下"这题我现在有 X 分"
```

::: exam 为什么要"先全部交一遍"
三个理由：

1. **锁定分数。** 交上去的分不会被后面的失误抹掉。
2. **心态稳定。** 手里有分之后，你的判断力会明显变好。
3. **防止全卷 0 分。** 每一题都有代码，就不会出现"某题压根没交"的情况
   （见[收录关](/practice/five-gates/collection)）。

**这一步做完，你就已经赢过一大半人了。**
:::

### ③ 主攻阶段（第 75 分钟～收尾前）

现在开始往上打。**从性价比最高的那道题开始**：

| 优先做 | 为什么 |
| --- | --- |
| 已经过半、再想一点就能满分的题 | 投入产出比最高 |
| 暴力基础上加一个优化的题 | 稳 |
| 有明确思路的题 | 比"感觉能做"的题可靠 |
| ❌ 完全没思路的题 | **先放着**，别现在碰 |

::: pitfall 卡住超过 10 分钟就换题
给自己一个硬规则：**一道题 10 分钟没有任何进展，就换下一题。**

"再想 5 分钟"是最贵的一句话——它经常变成"再想 50 分钟"。

**换题不是放弃**，是让大脑在后台继续想。很多人换到别的题上，
突然就想通了刚才那道题的思路。
:::

### ④ 收尾阶段（最后 30～40 分钟）

**这一阶段不改任何算法逻辑。** 只做检查：

完整清单见[申诉不是安全网](/practice/five-gates/appeal)，这里只列最关键的：

- [ ] 四题都**重新编译**一遍
- [ ] 四题都用**样例**跑一遍，用 `diff` 比对输出
- [ ] 每题 `freopen` 的文件名**逐字符**核对
- [ ] **目录结构**和源文件名正确
- [ ] 确认**每道题都提交成功**

::: exam 最后 30 分钟的收益被严重低估
改算法：收益不确定，**风险很高**（可能把 60 分改成 0 分），而且没时间验证。

做检查：收益确定。**光是"确认文件名没错"这一条，就可能救回一整道题。**

**选择题永远选确定的那个。**
:::

## 卡住的时候怎么办

| 症状 | 该做什么 |
| --- | --- |
| 10 分钟没思路 | **换题** |
| 有思路但写不出来 | 先写暴力交上去，再回来 |
| 代码调不出来 | 先 `cerr` 打印中间值定位（见[结果关](/practice/five-gates/result)） |
| 样例过了但心里没底 | 用[对拍](/practice/stress-testing)验证，或者补测边界 |
| 完全懵了、手在抖 | **停下来，深呼吸，喝口水**。慌着写的代码 90% 有错 |

::: pitfall 慌了的时候，做"不需要思考的事"
如果心态崩了，不要强迫自己想算法。改成做这些：

1. **默打一遍模板**，写一道最水的题
2. **检查已经交上去的代码**（这一条永远是净收益）
3. **把四题的 `freopen` 再核对一遍**

**这些动作不看智力，只看习惯。** 做完之后，你通常会重新冷静下来，
而且分数只增不减。
:::

## 心态：三条

::: range 考场上真正有用的三句话
1. **"我不会做的题，别人也不一定会。"**
   不要因为一道题卡住就断定自己完了。

2. **"拿到手的分才是分。"**
   纠结"这题本来应该做出来的"没有任何价值。把注意力放在"我还能拿多少"。

3. **"按计划走，不按感觉走。"**
   时间表是考前定好的。感觉慌乱的时候，回到时间表上，看现在该做哪一步。
:::

## 突发情况

| 情况 | 正确做法 |
| --- | --- |
| 电脑死机 / 断电 | **立刻举手找监考老师**，不要自己重启折腾 |
| 代码丢失 | 回答题盘上找；平时**每 10 分钟 `Ctrl + O` 存盘** |
| 身体不适 | 立刻举手。硬撑会影响整场考试 |
| 发现交错了题 | 举手说明，按监考老师指示处理 |
| 周围人做得很快 | **不要看别人**。他可能正在把代码越改越错 |

::: exam 一条纪律：不比较
考场上最容易毁掉状态的，是"旁边的人已经翻页了"。

**你不知道他在写什么，也不知道他写得对不对。** 盯着自己的屏幕，
按自己的时间表走——这是你唯一能控制的事。
:::

## 赛后复盘模板

每打完一场模拟赛，花 10 分钟填这张表。**它比多做一套题更有用。**

```text
日期：____    总分：____

一、时间账
  通读用了 __ 分钟（计划 15）
  拿分阶段结束时，四题各有 __ 分
  卡住最久的一题：____，卡了 __ 分钟（超过 10 分钟了吗？）

二、丢分账（每一分都要归类）
  □ 算法不会        → 记下知识点：____
  □ 复杂度不够      → 数据范围看漏了吗？____
  □ 边界没测        → 哪个边界：____
  □ 文件关 / 收录关 → 这是最不该丢的
  □ 溢出 / 类型     → ____
  □ 时间不够没写完  → 时间分配问题

三、下次改一件事
  只写一件：____
```

::: range 为什么"只改一件事"
一次列十条改进项，你一条也改不了。

**每场比赛只挑一个最值钱的习惯去改**（比如"这周专门练先交暴力"），
三场比赛之后，你的得分结构会明显变化。
:::

## 动手检查

1. 按 4 小时**限时**做一套完整的四题卷，全程记录每个阶段实际用了多久。
2. 填一遍上面的复盘模板，看看你的分主要丢在哪一类。
3. 给自己定一个"卡住 10 分钟就换题"的规则，下场模拟赛严格执行，看效果。
4. 把四阶段时间表抄成一张纸，模拟赛时放在旁边。

## 立即练习

| 难度 | 练习 | 练什么 |
| --- | --- | --- |
| 基础 | 掐表通读一套四题卷，只用 15 分钟，写出四题的算法和分档 | 通读阶段 |
| 基础 | 限时 1 小时，只做"四题都交一份暴力" | 拿分阶段 |
| 巩固 | 完整模拟一场，最后 30 分钟严格只检查 | 收尾纪律 |
| 巩固 | 填一次复盘模板，并定下"下次只改的一件事" | 复盘能力 |
| 挑战 | 找同学同做一套卷，比较两人的时间分配差异 | 看见分配的价值 |
