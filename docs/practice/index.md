# 考前实战

**这一部分不教算法，只解决一件事：把已经会的分数，一分不少地落到成绩单上。**

复赛的分数，一半来自算法，一半来自工程。算法要长期训练，工程**两天就能养成习惯**。

## 学完你会做到

- 用"三种 0 分"框架**自诊断**每一次丢分
- 从**收录关到资源关**逐关检查自己的模板
- 拿到题先看数据范围，判断该写什么、**该先交什么**
- 手上有一张可以贴在显示器上的**交卷检查清单**

## 什么时候看

| 时机 | 看什么 | 怎么用 |
| --- | --- | --- |
| **考前两周** | 五道关全部 + 数据范围表 | 逐条对照自己的模板改 |
| **考前三天** | 交卷清单 + 必背模板 | 默打模板，练成肌肉记忆 |
| **考前一夜** | [五道关总纲](/practice/five-gates/) + 清单 | **只读清单，不学新东西** |

::: pitfall 考前一天不要翻快速入门
那时候你需要的是**清单**，不是知识点。
考前一晚学新算法，收益接近于零，还会打乱已有的熟练度。
:::

## 两条纪律

::: exam 这一部分的两条核心纪律
1. **最后 30 分钟只检查，不改逻辑。**
   交卷前改算法是负收益——你可能把能过 60 分的程序改成 0 分，而且没时间再验证。

2. **具体规定以本省当年须知为准。**
   目录结构、提交方式、大小写要求在各省之间并不一致，规则也逐年可能调整。
   本书给的是**框架和习惯**，具体条条框框一律以你所在省份的官方须知和监考老师说明为准。
:::
