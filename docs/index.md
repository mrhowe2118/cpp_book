## 这本书怎么用

不要指望"看完就会"。每读完一节，立刻写代码验证，并做完文章最后的练习。

推荐节奏：

1. **先跑通环境**，再学语法。环境不通，后面每一步都在怀疑自己。
2. **每节至少写完一道练习**，不要只看示例代码。
3. **不会的题先手算**。把样例在纸上跑一遍，再回到代码。
4. **基础打完后**再进 STL 和考前实战。

## 两条主线

这本书里有两种内容，请分场合使用：

| | 系统学（快速入门 / STL） | 考前救（考前实战） |
| --- | --- | --- |
| 什么时候看 | 平时，一周几节 | 考前两周、考前一夜 |
| 目的 | 把语法和算法学明白 | **改变一个考场动作** |
| 读法 | 边读边写，做完练习 | 对照自查，把清单贴在显示器上 |

系统学是把分数上限抬高，考前救是**把已经会的分数保住**。
两者不冲突，但**不要在考前一天翻快速入门**——那时候你需要的是清单。

## 从这里开始

- **完全没写过代码**：从 [《开始编程》](/guide/getting-started) 起步，先让环境跑通
- **会写，但总丢分**：直接读 [《爆零五道关》](/practice/five-gates/)——算法之外的失分全在这里
- **已经能做出题，想稳住一等**：先看 [《数据范围表就是给分表》](/practice/data-range)
